# 동아리 회계 디자인

디자인 의도를 적는 문서. **값은 토큰 파일에만 둔다** (macOS `DesignSystem/Tokens.swift`, Web `tokens.css`).
실제 모습은 디자인 카탈로그(개발 모드)에서 확인한다.

## 컨셉

어머니가 돋보기 없이 쓰는 큰 글씨 가계부. 차분한 청록 한 가지 색과 넓은 여백, 꾸밈 없이 "지금 남은 돈"이 먼저 보인다.

## 원칙

- 글자는 크게: 본문 18px 이상, 금액 24px 이상, 잔액 32px 이상. 14px 미만 금지.
- 누르는 곳은 56px 이상, 기호만 있는 버튼 금지(항상 글자 포함).
- 한 화면에 주 버튼 하나. 위에서 아래로 한 방향 흐름.
- 쉬운 말: "들어온 돈/나간 돈", "작년에서 넘어온 돈(이월금)".
- 색만으로 구분하지 않는다: 수입 파랑·지출 빨강 + 부호(+/−).
- 시제품: https://claude.ai/artifact/KfbCpZBE6H42ZUdBJSLRvE

## 토큰 역할

값은 `src/styles/tokens.css` 에만 있다. 이름은 Tailwind v4 테마 변수(`--color-*`, `--text-*`, `--radius-*` 등)와 겹치지 않게 지었다. 겹치면 v1 화면의 Tailwind 값이 바뀐다.

## 컴포넌트

`src/ui/`. 카탈로그 `/#/dev/catalog` (개발 모드 전용)에 아래 상태가 전부 있다.

| 컴포넌트 | 상태 |
|---|---|
| `Button` | 주 / 보조 / 위험 / 위험 글자형 × 기본·비활성, 키보드 포커스 |
| `BigActionButton` | 돈 들어옴(+) / 돈 나감(−) × 기본·비활성, 보조 설명 줄 |
| `ChoiceChip` | 선택됨 / 안됨 / 비활성 (`aria-pressed`) — 월 12칸, 항목 |
| `MoneyInput` | 빈칸 / 입력됨(콤마·"원") / 포커스 / 오류(문장 안내) / 비활성, 상한 999,999,999 |
| `ConfirmDialog` | 기본 / 위험(빨강 확인), 열리면 "아니요"에 포커스, Esc = 아니요 |
| `Toast` | 보이는 중 / 사라짐 (기본 2초, `role="status"`) |
| `TabBar` | 장부·보고서·설정 × 지금 탭 / 다른 탭, 아이콘 + 글자, 하단 고정 + safe-area |

공통 규칙: 기호만 있는 버튼 없음(항상 글자), 누르는 곳 `--touch-min` 이상, 포커스 링 보임, 컴포넌트는 토큰 변수만 쓰고 `className`·`style` 을 받지 않는다. 루트에 `data-testid`, 상태가 있으면 `data-state`/`data-variant`/`data-kind`.

## 접근성

- 다크 모드: 시스템 설정을 따른다. `data-theme="light" | "dark"` 를 단 요소 안에서는 그 테마로 고정(카탈로그 전환 토글이 이 방식).
- 동작 줄이기: `prefers-reduced-motion` 이 켜져 있으면 나타남 효과와 색 전환을 쓰지 않는다.
- 대비: 본문·보조 글자 모두 WCAG AA 이상. 수입/지출은 색 + 부호(+/−)로 구분, 선택된 칩은 색 + 굵기로 구분.
