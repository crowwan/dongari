# 동아리 회계 디자인

디자인 의도를 적는 문서. **값은 토큰 파일에만 둔다** (Web `src/styles/tokens.css`).
실제 모습은 디자인 카탈로그(개발 모드 `/#/dev/catalog`)에서 확인한다.

## 컨셉

> 2026-10-07 디자인 개편(ADR 004) — 기준 시안: https://claude.ai/artifact/MSDNF1M41QotjmG49VXvYh , 결정: `docs/decisions/004-design-renewal.md`. 기초 토큰·글꼴·아이콘·공통 부품은 #45 에서 시안대로 바꿨고, 화면 배치는 개편 2·3·4(#46 장부·설정, #47 내역 적기, #48 정리 화면)에서 바꾼다.

어머니가 돋보기 없이 쓰는 큰 글씨 가계부. 개인 디자인 시스템(`~/Works/personal/design-system/CONCEPT.md`)의 뼈대 — 푸른 기 없는 순수 회색 계층, 옅은 회색 바탕 위 흰 카드, 테두리 대신 면과 여백 — 위에 토스 TDS 의 부품 패턴(원형 아이콘 줄, 한 몸통 스위치, 아래에서 올라오는 선택 창, 아래 고정 주 버튼)을 얹었다. 브랜드 짙은 청록은 화면마다 주 버튼 하나에만 쓰고, 꾸밈 없이 "지금 잔액"이 먼저 보인다.

## 원칙

- 글자 크기는 개인 디자인 시스템 기본값(짝수만): 잔액·금액 30 Bold("원"은 60%), 화면 제목 24, 질문·카드 제목 20, 줄 이름 16 SemiBold, 본문 16, 보조 14. 14px 미만 금지. **모두 rem** 이라 폰 글자 크기 설정을 키우면 같이 커진다.
- 글자 위계는 세 단계, 크기와 두께만으로 나눈다: 화면 제목 > 질문·카드 제목 > 줄 이름·보조 이름·안내. 아래 "타이포 위계와 간격 규칙".
- 묶음은 여백으로: 묶음 사이 간격이 묶음 안 간격보다 확실히 넓다 (`--group-gap` > `--stack` > `--stack-tight`). 화면 좌우 여백 24.
- 누르는 곳은 56px 이상(주 버튼 60, 입력칸·줄 선택·스위치 64, 아이콘 줄 72), 기호만 있는 버튼 금지(아이콘 옆에 늘 글자). 예외: 월 넘기기 ‹ › 는 화면 읽기 이름 "이전 달"/"다음 달", 가운데 달 글자와 한 줄로 읽힌다.
- 한 화면에 주 버튼 하나. 위에서 아래로 한 방향 흐름.
- 익숙한 말: "수입/지출", "잔액", "작년 이월금", "내역". "보고서" 대신 "월 정리"·"올해 결산".
- 색: 순수 회색 계층. 브랜드 짙은 청록은 주 버튼 채움에만(다크에서도 같은 진한 청록이라 튀지 않음). 고른 것은 옅은 청록 면 + 청록 글자, 수입 금액은 밝은 청록 + `+`, 지출 금액은 제목 글자색 + `−`. 위험(지우기)·오류만 빨강 하나.
- 면으로 묶는다: 카드·버튼은 테두리 대신 면 색으로 구분. 그림자는 스위치 손잡이 한 곳만 아주 약하게. 선은 아래 고정 영역 위쪽, 장부 그 달 카드의 소계 두 칸 사이 세로선(시안), 옛 부품(입력칸·선택 버튼)의 둘레에만.
- 색만으로 구분하지 않는다: 수입/지출은 부호(+/−)와 아이콘(⊕/⊖), 선택은 채움 + 굵기, 이번 달은 테두리, 비활성은 점선·면 없음, 오류는 테두리 + 문장.
- 아이콘: Lucide 선 아이콘(폰 앱에서 흔한 모양)만. 항목 아이콘은 이름으로 자동(`domain/itemIcon`).

## 타이포 위계와 간격 규칙

#42 에서 역할 구조를, #45 에서 크기를 DS 기본값으로 맞췄다.

**글자 위계 3단** — 크기와 두께만으로 나눈다 (색은 보조 글자에만 `--muted`)

| 단계 | 역할 토큰 | 쓰는 곳 |
|---|---|---|
| 1 큰 숫자·화면 제목 | `--text-display-*`, `--text-title-*` (Bold) | 잔액·금액, 화면마다 제목 하나 |
| 2 질문·카드 제목 | `--text-heading-*` (Bold) | 내역 적기 질문, 시작 화면 입력칸 이름, 설정 카드 제목, 월 정리 카드 제목, 선택 창 제목 |
| 3 줄 이름·보조 이름·안내 | `--text-row-*` (SemiBold) / `--text-label-*` (Medium) / `--text-body-*` / `--text-caption-*` (`--muted`) | 내역 줄 이름 / "직접 적기", 글자 버튼 / 본문 / 보조 설명 |

- 입력칸 이름(`TextField`·`MoneyInput` `label`)은 기본이 2단계, 질문 아래 딸린 칸·카드 안 칸은 `labelRole="label"` 로 3단계.
- "직접 적기"는 placeholder 로 옮기지 않고 보이는 보조 이름으로 남긴다(큰 글씨 사용자는 사라지는 placeholder 를 놓치기 쉽다).

## 아이콘

`src/ui/Icon.tsx` 한 곳에서 `lucide-react` 아이콘을 이름(`IconName`)으로 고른다. 쓴 아이콘만 번들에 들어간다(트리셰이킹, 22개). 시안의 SVG 를 직접 옮기지 않고 Lucide 를 고른 이유: 시안 아이콘 대부분이 이미 Lucide 모양이고, 선 두께·모서리가 한 세트로 맞춰져 있으며(DS "fill/line 혼용 금지, 두께 통일"), 새 아이콘이 필요할 때 같은 세트에서 고르면 된다.

| 이름 | 모양 | 쓰는 곳 |
|---|---|---|
| `users` / `building` / `cup` / `gift` / `bank` / `flower` / `receipt` | 사람들 / 건물 / 컵 / 선물 / 은행 / 꽃 / 영수증 | 항목 아이콘 — `itemIcon(name)` 이 이름으로 고른다 |
| `income` / `expense` | ⊕ / ⊖ | 수입 / 지출 |
| `calendar` / `pen` / `download` / `share` / `folder` / `chart` / `settings` / `phone` / `plus` / `check` | 달력 / 연필 / 아래 화살표 / 공유 / 폴더 / 막대그래프 / 톱니 / 스마트폰 / 더하기 / 체크 | 달, 직접 적기, 사진 저장, 백업 보내기, 백업 불러오기, 결산, 설정, 홈 화면에 추가(폰 홈 화면 — 집 모양은 "우리 집"으로 읽힐 수 있어 폰 모양), 내역 적기, 저장·적은 내용 |
| `left` / `right` / `down` | ‹ / › / ▾ | 장부로·이전 달 / 다음 달·바꾸기 / 달 고르기 |

`itemIcon(name)`(`src/domain/itemIcon.ts`, SPEC-001 AC-18): 위에서부터 처음 맞는 말 — 회비·회원 → 사람들, 대관·장소·임대 → 건물, 간식·커피·음료·다과 → 컵, 지원금·후원·선물 → 선물, 이자·예금·은행 → 은행, 꽃 → 꽃, 그 밖 → 영수증. 아이콘은 늘 화면 읽기에서 숨기고(`aria-hidden`), 뜻은 옆 글자가 전한다.

### 선택 창과 뒤로 버튼 (`useScreenHistory`, #46)

선택 창(`BottomSheet`)이나 설정 편집 화면처럼 화면 위에 잠깐 뜨는 것은 **방문 기록 한 칸**으로 연다. 그래야 안드로이드 뒤로 버튼이 창만 닫고 앱이나 화면을 나가지 않는다.

```tsx
const history = useScreenHistory()           // 화면 컴포넌트는 SheetHistory(sheet·openSheet·closeSheet)만 받는다
<MonthStepper onPickMonth={() => history.openSheet('ledger-month')} … />
<BottomSheet open={history.sheet === 'ledger-month'} title="몇 월을 볼까요?" onClose={history.closeSheet}>
  <MonthPicker value={month} onChange={(m) => { setMonth(m); history.closeSheet() }} />
</BottomSheet>
```

- `openSheet(이름)`: `{ screen, sheet }` 한 칸을 쌓고 `sheet` 가 그 이름. 이미 열려 있으면 칸을 더 쌓지 않고 바꿔 끼운다. 이름은 화면마다 겹치지 않게(`'ledger-month'`, `'settings-year'` …).
- 뒤로 버튼: 창이 열려 있으면 창만 닫는다. "적던 내용을 버릴까요?" 확인보다 먼저다(창을 닫은 뒤 다음 뒤로 버튼에서 묻는다).
- 화면에서 닫기(고르기·바깥·Esc·[‹ 설정]): `closeSheet()` 가 그 칸을 `back()` 으로 되돌린다. 이 popstate 는 화면을 바꾸지 않는다.
- 고르자마자 장부로 갈 때(설정 연도): `closeSheet()` 를 부르지 말고 `backToLedger()` 하나만 — 창 칸과 화면 칸을 `history.go(-2)` 로 한 번에 되돌린다.
- 다른 화면을 열거나 장부로 돌아오면 창은 닫힌 상태로 시작한다.
- 내역 적기·고치기(#47): 달 알약·"바꾸기" 의 달 선택 창(`'entry-month'`, `EntryMonthSheet`)도 이 방법으로 연다. 창이 열린 채 [저장] 할 일은 없지만, 저장 뒤 `backToLedger()` 는 창이 열려 있어도 두 칸을 되돌린다. 하나씩 채우기는 처음 상태(보던 달만)에서 답한 것이 하나라도 있으면 `confirmBeforeLeave(true)`.

공통 규칙: 누르는 곳 `--touch-min` 이상, 포커스 링 보임, 그림자 없음(스위치 손잡이 제외), 컴포넌트는 토큰 변수만 쓰고 `className`·`style` 을 받지 않는다. 루트에 `data-testid`, 상태가 있으면 `data-state`/`data-variant`/`data-kind`/`data-tone`.

### 토큰 예외: 올해 결산 양식

`src/features/report/sheet/*` 는 색·글자 크기를 토큰 대신 **인라인 hex·px** 로 쓴다 (`sheetStyles.ts`). 앱 화면이 아니라 사진으로 저장해 단톡방에 올리는 v1 종이 양식이라 테마·토큰이 바뀌어도 v1 과 똑같이 흰 종이·검정 글자·회색 선이어야 하고(SPEC-003 AC-7), 사진을 만드는 html2canvas 1.4 가 oklch() 같은 최신 색 문법을 읽지 못해 평범한 hex 로 그렸다. 글자(11~14px)도 v1 양식 크기라 14px 미만 금지 기준의 예외이고, 대신 화면에서는 두 손가락으로 확대해 본다.

### 사진으로 저장할 때의 모양

- 월 정리 사진은 화면 모양(토큰)을 그대로 쓰되, 사진으로 그리는 복사본에만 `data-theme="light"` + `data-capturing` 을 단다. 흰 바탕 위에서는 흰 카드가 면으로 구분되지 않으므로 사진에서만 카드 둘레에 `--line` 선을 두른다 (`report.css`).
- 사진에서는 자간(`letter-spacing`)과 숫자 폭 맞춤(`tabular-nums`)을 끈다. html2canvas 1.4 는 자간이 있으면 글자를 한 자씩 그리면서 숫자 폭 맞춤을 읽지 못해 "1 40,000" 처럼 숫자 사이가 벌어진다 (#48).
- 올해 결산 사진은 화면에서 줄여 보이던 양식을 줄이지 않은 360px 그대로 2배로 그린다.

## 접근성

- 다크 모드: 시스템 설정을 따른다. `data-theme="light" | "dark"` 를 단 요소 안에서는 그 테마로 고정(카탈로그 전환 토글). 다크는 같은 역할을 유지한 채 고른 것·수입 글자를 밝게 뒤집는다. 주 버튼 채움은 다크에서도 같은 진한 청록이다 — 버튼 면과 바탕 대비(2.58:1)는 WCAG 1.4.11 대상이 아니고(버튼은 7.44:1 글자로 알아본다), 다크에서 밝은 청록 채움이 튀던 문제(ADR 004)를 막는다.
- 동작 줄이기: `prefers-reduced-motion` 이 켜져 있으면 나타남·올라옴 효과와 색 전환을 쓰지 않는다.
- 대비: 라이트·다크 모두 글자는 쓰이는 모든 면(바탕·카드·회색 면·눌림·옅은 청록·안내 띠·손잡이)에서 WCAG AA(4.5:1) 이상, 포커스 링·이번 달 테두리는 3:1 이상. 측정 결과는 #45 PR.
- 폰 글자 크기: 글자 크기 토큰이 모두 rem 이라 루트 글자 크기를 따른다 (`src/styles/tokens.test.ts`).
- 수입/지출은 색 + 부호(+/−) + 아이콘, 선택은 색 + 굵기, 비활성은 점선·면 없음으로 구분한다.
