# SPEC-001 한 줄 장부 입력

## 배경과 목표

v1 은 월별 수입 총액, 월별 지출 상세, 연간 수입내역을 따로 적고 합계를 직접 맞춰야 해서 "어디에 뭘 넣을지" 헷갈렸다. 같은 돈을 두 번 적는 구조가 원인이다.

리뉴얼 후에는 **돈이 오갈 때마다 한 줄(언제·무엇·얼마)만 적는다.** 월별 합계, 지출 상세, 수입내역, 잔액은 앱이 계산한다. 합계를 맞추는 일은 사라진다.

## 동작 정의

### 화면 구성 (탭 없음)

| 화면 | 여는 방법 | 역할 |
|---|---|---|
| **장부** (첫 화면) | 앱을 열면 | 잔액 + 한 달씩 보기 + 아래 고정 [+ 내역 적기] |
| **내역 적기 / 고치기** | [+ 내역 적기], 기록 줄 누르기 | 아래 "기록 입력" |
| **월 정리** | 장부 화면 [N월 정리 보기] | SPEC-003 |
| **올해 결산** | 장부 화면 위쪽 [올해 결산] | SPEC-003 |
| **설정** | 장부 화면 위쪽 [설정] | 동아리 이름, 연도, 이월금, 백업 (SPEC-002) |

장부 외 화면은 위쪽 [← 장부로] 와 안드로이드 뒤로 버튼으로 장부로 돌아온다.

### 장부 화면

```
┌───────────────────────────────┐
│ 한랑드림        [올해 결산][설정]│
│ 2026년                         │
│ ┌───────────────────────────┐ │
│ │ 지금 잔액                  │ │
│ │ 1,166,193원       (34px+)  │ │
│ │ 작년 이월 370,482원 포함    │ │
│ └───────────────────────────┘ │
│  [‹]        9월         [›]   │  ← 한 달씩 넘기기
│ ┌───────────────────────────┐ │
│ │ 수입 140,000원 지출 98,280원│ │  ← 그 달 소계
│ │ 회비            +140,000원 │ │
│ │ 대관료           −40,000원 │ │
│ │ 간식비           −58,280원 │ │
│ │      [ 9월 정리 보기 ]      │ │
│ └───────────────────────────┘ │
├───────────────────────────────┤
│        [ + 내역 적기 ]         │  ← 화면 아래 고정, 높이 64px
└───────────────────────────────┘
```

- 처음 보이는 달: 올해 장부면 이번 달, 지난 연도 장부면 12월.
- [‹] [›] 로 1~12월을 넘긴다. 1월에서 [‹], 12월에서 [›] 는 비활성.
- 기록은 그 달 안에서 입력 순. 기록 한 줄을 누르면 고치기 화면이 열린다.
- 그 달 기록이 없으면 "9월에 적은 내역이 없어요. 아래 [+ 내역 적기] 로 적어 보세요" 안내, [9월 정리 보기] 는 숨긴다.
- [+ 내역 적기] 는 목록을 내려도 화면 아래에 늘 보인다.

### 기록 입력 (한 화면, 위에서 아래로)

[+ 내역 적기] 를 누르면 전체 화면 입력창("내역 적기")이 뜬다.

1. **몇 월인가요?** — 기본값은 장부 화면에서 보고 있던 달. 1~12월 버튼(4열 × 3행).
2. **수입인가요, 지출인가요?** — [수입] [지출] 큰 버튼 두 개. **기본값 없음**(잘못 저장되면 잔액이 크게 틀어지므로).
3. **무엇인가요?** — 자주 쓴 항목이 버튼으로 먼저 보인다. 없으면 직접 입력.
   - 항목 버튼을 누르면 이름이 채워지고, 그 항목을 마지막으로 쓴 종류(수입/지출)가 2번에 **자동 선택**된다. 기본 항목은 대관료·간식비 = 지출, 회비 = 수입.
   - 2번을 고르기 전에는 두 종류의 자주 쓴 항목을 최근 사용 순으로 섞어 최대 6개, 고른 뒤에는 그 종류만 최대 6개.
   - 같은 종류로 쓴 이름을 최근 사용 순, 중복 없이. 지난 연도 기록도 포함한다. 6개보다 적으면 기본 항목으로 채운다.
4. **얼마인가요?** — 숫자 키패드가 뜨는 입력칸, 천 단위 콤마 자동, "원" 표기.
5. **[저장]** — 하단 고정 큰 버튼. 저장 후 장부로 돌아가 그 기록의 달을 보여 주고 "저장했어요" 알림이 2초 보인다.

- 고치기 화면("내역 고치기")은 같은 모양에 값이 채워져 있고, 맨 아래 [이 내역 지우기] 텍스트 버튼이 있다.
- 지우기는 "정말 지울까요?" 확인(앱 안 다이얼로그) 후 지운다.

### 연도

- 앱은 기본으로 올해 장부를 연다. [설정] 에서 연도를 바꿔 지난 장부를 볼 수 있다. 고를 수 있는 연도는 장부가 있는 연도와 올해다.
- 새 연도 장부를 처음 만들 때, 전년도 장부가 있으면 **전년도 잔액을 이월금으로 자동 채운다.** (수정 가능)

### 첫 실행

- 장부가 하나도 없으면 "동아리 이름"과 "작년 이월금" 두 칸만 묻고 시작한다.
- 동아리 이름이 비어 있으면 [시작하기] 를 누를 수 없다.
- 이월금은 금액을 양수로 적고 [남았어요] / [적자였어요] 중 하나를 고른다(기본 남았어요). 적자였어요면 음수로 저장한다. 숫자 키패드에서 빼기표를 찾지 않아도 되게 하기 위해서다. 설정의 이월금 수정도 같은 모양이다.
- 장부는 있지만 고른 연도 장부가 없으면 같은 두 칸으로 새 연도 장부를 만든다. 동아리 이름은 앞선 가장 가까운 연도 장부에서, 이월금은 전년도 잔액(전년도 장부가 없으면 0)으로 채워 둔다.

### 큰 글씨·쉬운 말 기준 (모든 화면 공통)

- 본문 18px 이상, 금액·핵심 숫자 24px 이상, 잔액 32px. 14px 미만 금지.
- 누르는 영역 최소 56px. 기호만 있는 버튼 금지(항상 글자 포함).
- 한 화면에 주 버튼은 하나.
- 용어: 회계 담당자에게 익숙한 "수입/지출", "잔액", "작년 이월금", "내역". "보고서" 대신 "월 정리", "올해 결산", 공유는 "사진으로 보내기".
- 색: 강조색은 차분한 짙은 청록 하나(주 버튼). 수입 금액은 차분한 초록 + `+`, 지출 금액은 본문색 + `−`. 원색 파랑·빨강은 쓰지 않는다. 색만으로 구분하지 않는다.
- 텍스트 대비 WCAG AA 이상.

### 예외와 경계 상황

- 수입/지출 미선택, 항목 이름 빈칸, 금액 0 또는 빈칸 중 하나라도 있으면 [저장] 비활성 + 빠진 것 안내("수입인지 지출인지 골라 주세요" / "무엇인지 적어 주세요" / "얼마인지 적어 주세요").
- 금액 상한 999,999,999원. 이월금은 −999,999,999 ~ 999,999,999원 정수.
- 항목 이름과 동아리 이름은 앞뒤 공백을 지우고 저장한다.
- 입력 도중 뒤로가기(안드로이드 뒤로 버튼 포함)를 누르면 입력창만 닫힌다(앱이 나가지지 않음). 입력한 내용이 있으면 "적던 내용을 버릴까요?" 확인.

## 수용 기준

- [ ] AC-1 [+ 내역 적기] → 월·수입/지출·항목·금액 입력 → [저장] 하면 장부 화면이 그 달을 보여 주고 기록이 추가돼 있다 (자동)
- [ ] AC-2 기록을 추가·수정·삭제하면 잔액 = 이월금 + 수입 합 − 지출 합 으로 즉시 다시 계산된다 (자동)
- [ ] AC-3 입력 화면의 월 기본값은 장부 화면에서 보고 있던 달이고, 올해 장부의 첫 화면은 이번 달을 보여 준다 (자동)
- [ ] AC-4 한 번 이상 쓴 항목 이름이 다음 입력 때 버튼으로 보이고, 누르면 이름 칸이 채워지며 그 항목의 수입/지출이 자동 선택된다 (자동)
- [ ] AC-5 수입/지출, 이름, 금액 중 하나라도 비어 있으면 [저장] 이 비활성이고 빠진 것을 안내한다 (자동)
- [ ] AC-6 기록을 눌러 수정하고 저장하면 목록과 합계에 반영된다 (자동)
- [ ] AC-7 [이 내역 지우기] → 확인 시에만 삭제된다 (자동)
- [ ] AC-8 새 연도 장부를 만들면 전년도 잔액이 이월금 기본값으로 들어간다 (자동)
- [ ] AC-9 장부 화면은 한 달씩 보이고 [‹] [›] 로 1~12월을 넘기며 그 달의 수입·지출 소계와 기록(입력 순)이 보인다. 1월에서 [‹], 12월에서 [›] 는 비활성이다 (자동)
- [ ] AC-10 금액 칸에서 폰 숫자 키패드가 뜬다 (`inputmode="numeric"`) (수동 QA)
- [ ] AC-11 390px 폭 화면에서 14px 미만 글자, 56px 미만 터치 영역이 없다 (수동 QA)
- [ ] AC-12 입력창에서 안드로이드 뒤로 버튼을 누르면 입력창만 닫힌다 (수동 QA)
- [ ] AC-13 어머니가 설명 없이 지출 1건, 수입 1건을 적을 수 있다 (수동 QA — 사용성 테스트)
- [ ] AC-14 [+ 내역 적기] 는 기록이 많아 화면을 내려도 화면 아래에 늘 보인다 (수동 QA)

## 범위 밖

- 날짜(일) 단위 기록 — 보고서가 월 단위라 월만 받는다
- 항목 분류/카테고리 관리 화면
- 검색, 필터

## 기술 메모

- 화면 구조: `features/ledger`(장부·입력), `features/report`(월 정리·올해 결산), `features/settings` 로 나누고, 계산은 순수 함수(`domain/ledger.ts`)로 분리해 단위 테스트한다.
- 상태: `useLedger()` 훅이 저장소(SPEC-002)를 감싼다. 외부 상태 라이브러리는 도입하지 않는다.
- 토큰: `src/styles/tokens.css` 에 큰 글씨 기준 토큰 정의, 컴포넌트는 토큰만 사용. (공용 design-system 은 토큰 파일 미작성이라 아직 소비하지 않음)
- 디자인 카탈로그 `/#/dev/catalog` (개발 모드 전용).
- 뒤로가기: 입력창 열 때 `history.pushState`, `popstate` 로 닫기.

## 결정

- 자주 쓰는 항목은 최근 사용 순 최대 6개, 모자라면 기본 항목으로 채운다. 저장하지 않고 기록에서 계산한다 (#11)
- 음수 이월금은 빼기표 입력 대신 [남았어요]/[적자였어요] 선택으로 받는다 (#12)
- 화면은 탭 없이 장부 한 화면 + 한 달씩 보기, 아래 고정 [+ 내역 적기] 하나. 수입/지출은 입력 화면에서 고른다 (기본값 없음, 항목 버튼으로 자동 선택). 디자인은 "맑은 은행 앱" 스타일 + 차분한 청록 강조색. 근거: [ADR 003](../decisions/003-month-view-layout.md)
