# SPEC-001 한 줄 장부 입력

## 배경과 목표

v1 은 월별 수입 총액, 월별 지출 상세, 연간 수입내역을 따로 적고 합계를 직접 맞춰야 해서 "어디에 뭘 넣을지" 헷갈렸다. 같은 돈을 두 번 적는 구조가 원인이다.

리뉴얼 후에는 **돈이 오갈 때마다 한 줄(언제·무엇·얼마)만 적는다.** 월별 합계, 지출 상세, 수입내역, 잔액은 앱이 계산한다. 합계를 맞추는 일은 사라진다.

## 동작 정의

### 화면 구성 (탭 없음)

| 화면 | 여는 방법 | 역할 |
|---|---|---|
| **장부** (첫 화면) | 앱을 열면 | 잔액 + 한 달씩 보기 + 아래 고정 [+ 내역 적기] |
| **내역 적기 / 고치기** | [+ 내역 적기], 기록 줄 누르기 | 아래 "기록 입력" |
| **월 정리** | 장부 화면 [N월 정리 보기] | SPEC-003 |
| **올해 결산** | 장부 화면 위쪽 [결산] | SPEC-003 |
| **설정** | 장부 화면 위쪽 [설정] | 동아리 이름, 연도, 이월금, 백업 (SPEC-002). 아래 "설정 화면" |

장부 외 화면은 위쪽 [← 장부로] 와 안드로이드 뒤로 버튼으로 장부로 돌아온다. 장부에서 뒤로 버튼은 앱 기본 동작(나가기)이다. 장부로 돌아오면 떠나기 전에 보던 달을 그대로 보여 준다.

### 장부 화면

```
┌───────────────────────────────┐
│ 한랑드림       [📊 결산][⚙ 설정]│  ← 아이콘 + 글자
│ 2026년                         │
│ ┌───────────────────────────┐ │
│ │ 지금 잔액                  │ │
│ │ 1,166,193원 (숫자 30, 원 작게)│ │
│ │ 작년 이월 370,482원 포함    │ │
│ └───────────────────────────┘ │
│  [‹]       10월 ▾        [›]  │  ← 한 달씩 넘기기 (가운데 = 달 선택 창)
│ ┌───────────────────────────┐ │
│ │ 수입 140,000원 │ 지출 98,280원│ │  ← 그 달 소계
│ │ (👥) 회비      +140,000원  │ │  ← 원형 아이콘 + 이름 + 금액
│ │ (🏢) 대관료     −40,000원  │ │
│ │ (☕) 간식비     −58,280원  │ │
│ │     [ 10월 정리 보기 ]      │ │
│ └───────────────────────────┘ │
├───────────────────────────────┤
│        [ + 내역 적기 ]         │  ← 화면 아래 고정
└───────────────────────────────┘
```

- 위쪽 왼쪽은 동아리 이름(위)과 연도(아래), 오른쪽은 [결산] [설정] 아이콘 + 글자 버튼(막대그래프, 톱니바퀴).
- 가운데 달 이름(▾)을 누르면 아래에서 열두 달 선택 창 "몇 월을 볼까요?" 가 올라온다(3×4, 이번 달은 테두리, 지금 보는 달은 칠함). 달을 누르면 바로 창이 닫히고 그 달을 보여 준다(따로 [정하기] 버튼 없음). 바깥을 누르거나 안드로이드 뒤로 버튼을 누르면 창만 닫히고 보던 달 그대로다. 지난 연도 장부에는 이번 달 테두리가 없다.
- 잔액 카드 보조 줄: 작년 이월금이 있으면 "작년 이월 N원 포함", 적자였으면 "작년 적자 N원 포함"(빼기표 대신 "적자"), 0원이면 보조 줄을 숨긴다.
- 처음 보이는 달: 올해 장부면 이번 달, 지난 연도 장부면 12월.
- [‹] [›] 로 1~12월을 넘긴다. 1월에서 [‹], 12월에서 [›] 는 비활성.
- 그 달 카드 맨 위에 수입·지출 소계를 두 칸으로(그 달에 없는 쪽은 0원).
- 그 달 카드의 소계 두 칸은 가운데 가는 세로선으로 나눈다.
- 기록은 그 달 안에서 입력 순. 한 줄 = 왼쪽 원형 아이콘(항목 이름으로 정함, 아래 "아이콘") + 이름과 그 아래 작은 "수입"/"지출" + 오른쪽 금액. 수입은 청록 원·초록 금액·`+`, 지출은 회색 원·본문색 금액·`−`. 기록 한 줄을 누르면 고치기 화면이 열린다.
- [N월 정리 보기] 는 카드 맨 아래 회색 면 버튼(영수증 아이콘 + 글자, 폭 채움).
- 그 달 기록이 없으면 "9월에 적은 내역이 없어요. 아래 [+ 내역 적기] 로 적어 보세요" 안내만 보이고 소계와 [9월 정리 보기] 는 숨긴다.
- [+ 내역 적기] 는 목록을 내려도 화면 아래에 늘 보인다.

### 기록 입력 (하나씩 채우기)

[+ 내역 적기] 를 누르면 전체 화면 "내역 적기" 가 뜬다. **지금 할 질문 하나만 보이고, 답하면 다음 질문이 나타난다.** 적는 내역 하나는 **"지금 적는 내역" 카드 하나**에 모인다: 답한 것은 카드 안에서 한 줄로 접히고(줄의 [바꾸기] 로 고친다), 지금 질문은 같은 카드 안 맨 아래에서 펼쳐진다. 근거: [ADR 004](../decisions/004-design-renewal.md).

```
│ 내역 적기                      │
│ ┏ 지금 적는 내역 ━━━━━━━━━━━┓ │  ← 흰 카드 + 청록 둘레(2px), 머리 작은 청록 글자
│ ┃ 달    10월          [바꾸기]┃ │  ← 답한 줄: 이름표 + 굵은 값(아이콘) + [바꾸기], 줄 사이 가는 선
│ ┃ 항목  🍵 간식비 · 지출 [바꾸기]┃ │
│ ┃┌─────────────────────────┐┃ │
│ ┃│ 얼마인가요?              │┃ │  ← 지금 질문: 카드 안 맨 아래, 옅은 면으로 펼침
│ ┃│ [        5,000 원 ]      │┃ │     (금액 칸·빠른 더하기 / 항목 목록 / 이름 칸 / 수입·지출)
│ ┃│ [+1만] [+5만] [+10만]    │┃ │
│ ┃└─────────────────────────┘┃ │
│ ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━┛ │
```

- 답한 줄은 두 개까지: **달**(값 "10월"), **항목**(값 "대관료 · 지출" — 이름과 수입/지출을 한 줄에). 위에서부터 달 → 항목. ✓ 동그라미는 쓰지 않는다(✓ 는 "장부에 들어감"에만 쓴다).
- 지금 질문(제목 + 그 답 칸)은 카드 안 맨 아래 펼친 칸에 있다. 진행 막대는 없다.
- 2026-10-07 미리보기 QA("적은 내용이 바로 눈에 안 띄어 내가 적은 것인지 못 알아봤다", "입력칸과 적은 내용이 떨어져 있다")로 "적은 내용" 카드와 질문을 한 카드로 합쳤다. 시안 https://claude.ai/artifact/8S8y4GuLU5xkVkHTRPxt7M "입력칸과 합치기" D.
- 2026-10-07 미리보기 QA("무엇이 입력된 내용인지 구분이 잘 안 된다")로 알약 줄을 이 카드로 바꿨다 (#56). 알약은 흰 면이 질문 아래 목록·금액 칸과 같아 "이미 적은 것"과 "지금 고를 것"이 섞여 보였다.

1. **처음** — 위쪽 카드에 달 줄 `📅 10월`(장부에서 보던 달)이 미리 있고, 질문 **"무엇인가요?"** 와 항목 목록이 보인다.
   - 목록 한 줄 = 원형 아이콘 + 이름 + 오른쪽 "수입/지출" 표시. 자주 쓴 이름을 최근 사용 순, 중복 없이 최대 6개(지난 연도 기록 포함, 모자라면 기본 항목: 대관료·간식비 = 지출, 회비 = 수입). 맨 아래 [✎ 직접 적기] 줄.
   - 항목을 누르면 이름과 그 항목을 마지막으로 쓴 종류(수입/지출)가 정해지고 바로 2로 넘어간다.
   - [직접 적기] 를 누르면 이름 입력칸(키패드가 바로 뜸)과 그 아래 [‹ 목록에서 고르기] 가 나온다. 이름을 적고 [다음](또는 키패드 [완료]) → 그 이름이 처음 쓰는 이름이면 **"수입인가요, 지출인가요?"** 를 한 몸통 스위치([⊕ 수입] [⊖ 지출], 기본값 없음)로 묻고, 고른 뒤 [다음] 을 누르면 2로(잘못 눌러도 고칠 수 있게 고르자마자 넘어가지 않는다). 예전에 쓴 이름(지난 연도 기록 포함)이면 그때 종류로 정해져 바로 2로. 기본 항목 이름이라도 써 본 적이 없으면 처음 쓰는 이름이다.
   - 카드에는 답한 것만 쌓인다: 지금 묻고 있는 값(적는 중인 이름, 새 이름의 수입/지출)은 카드에 올리지 않는다. 직접 적은 새 이름의 수입/지출을 묻는 동안 항목 줄은 "꽃값" 처럼 이름만 보인다.
2. **"얼마인가요?"** — 숫자 키패드가 바로 뜨고, 금액이 크게(숫자 30, "원" 작게) 보인다. 아래 [+1만] [+5만] [+10만] 빠른 더하기(눌러도 키패드가 닫히지 않는다). 천 단위 콤마 자동.
3. **[✓ 저장]** — 화면 아래 고정(키패드 바로 위). 금액이 0이면 비활성 + "얼마인지 적어 주세요". 누르면 그 내역이 바로 장부에 저장되고, 장부로 돌아가지 않고 **연달아 적기**(아래)로 다음 내역을 묻는다. 기기에 저장하지 못했으면 지금처럼 장부로 돌아가 위쪽에 저장 실패 안내(SPEC-002)만 보인다.

- 달 줄 [바꾸기] 를 누르면 열두 달 선택 창 "몇 월인가요?" 가 올라온다(누르면 바로 닫힘, 지금 질문 그대로). 항목 줄 [바꾸기] 를 누르면 1(항목 고르기)로 돌아간다(금액은 유지, 지금 이름이 목록에 있으면 체크). [바꾸기] 는 56px 이상이고 화면 읽기 이름은 "달 바꾸기"/"항목 바꾸기".

#### 연달아 적기 (v2.1)

어머니는 공책에 모아 둔 내역을 한꺼번에 옮겨 적는다. 한 건 저장할 때마다 장부로 돌아가 [+ 내역 적기] 를 다시 누르지 않도록, 내역 적기 화면에서 이어서 적는다.

```
┌───────────────────────────────┐
│ ←  내역 적기                   │
│ ✓ 장부에 넣었어요 · 2건         │  ← 면 없는 작은 회색 글자 목록
│   대관료              −40,000원 │
│   간식비 방금          −28,340원 │  ← 방금 저장한 줄 이름 옆 "방금"(청록)
│ ┏ 지금 적는 내역 ━━━━━━━━━━━┓ │
│ ┃ 달    10월          [바꾸기]┃ │  ← 마지막에 저장한 달을 이어 씀
│ ┃┌ 무엇인가요? ────────────┐┃ │
│ ┃│ (항목 목록 / 직접 적기)   │┃ │
│ ┃└─────────────────────────┘┃ │
│ ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━┛ │
├───────────────────────────────┤
│ [ 다 적었어요 ]                │  ← 아래 고정, 보조 버튼(옅은 청록)
└───────────────────────────────┘
```

- [✓ 저장] 하면 그 내역은 바로 장부에 저장된다(나중에 한꺼번에 저장하지 않는다). 화면은 1(무엇인가요?)로 돌아가고, 맨 위에 **"✓ 장부에 넣었어요 · N건"** 목록이 생긴다.
  - 면(카드) 없이 작은 회색 글자: 머리 ✓ + "장부에 넣었어요 · N건", 줄 = 이름 + 부호 붙은 금액. "지금 적는 내역" 카드보다 눈에 덜 띄어야 한다.
  - 저장한 순서대로, 방금 저장한 줄이 맨 아래 + 이름 옆 "방금"(청록). 최근 2줄만 보이고 N 은 전체 건수.
  - 줄은 누를 수 없다(고치기는 장부에서).
- 달은 마지막에 저장한 내역의 달을 이어 쓴다("지금 적는 내역" 카드의 달 줄, [바꾸기] 그대로). 항목·금액은 비운다.
- 화면 읽기 초점은 새 질문 제목으로 간다. 금액 키패드는 닫힌다.
- 한 건이라도 저장했으면 아래에 **[다 적었어요]**(보조 버튼)가 고정된다. 금액 단계에서는 [✓ 저장] 만 보인다(두 버튼을 나란히 두지 않는다). 하나도 저장하지 않았으면 [다 적었어요] 는 없다.
- [다 적었어요] 또는 [← 장부로]·뒤로 버튼 → 장부로 돌아가 **마지막에 저장한 내역의 달**을 보여 주고 "N건을 저장했어요" 알림(2초). 저장한 것이 없으면 지금처럼 그냥 닫힌다.
  - 다음 내역을 적던 중(값이 하나라도 달라짐)이면 지금처럼 "적던 내용을 버릴까요?" 를 묻는다. [버리기] 는 적던 한 건만 버리고 이미 저장한 내역은 그대로다.
- 저장한 내역은 장부에 이미 들어가 있으므로, 앱을 닫거나 화면을 나가도 사라지지 않는다. "저장한 내역" 카드는 이번에 내역 적기 화면에 들어와 저장한 것만 보인다(다시 들어오면 빈 상태로 시작).

**고치기("내역 고치기")는 값을 한눈에 봐야 해서 펼친 모양**: 몇 월(한 줄 + "바꾸기" → 달 선택 창) / 수입·지출 스위치 / 항목 목록(고른 종류의 항목만, 지금 이름 체크) + 그 아래 "직접 적기" 칸(지금 이름이 채워져 있음) / 금액이 한 화면에 위에서 아래로, 질문 사이 넓은 간격.

- 고치기 화면("내역 고치기")은 같은 모양에 그 기록 값이 채워져 있고, 맨 아래(금액 칸 밑, 고정 [저장] 위) [이 내역 지우기] 위험 글자형 버튼이 있다.
- 고쳐서 [저장] 하면 장부로 돌아가 그 기록의 달(달을 바꿨으면 바뀐 달)을 보여 주고 "고쳤어요" 알림이 2초 보인다.
- 지우기는 "이 내역을 정말 지울까요?" 확인(앱 안 다이얼로그, [아니요] [지우기]) 후 [지우기] 를 눌렀을 때만 지운다. 지우면 장부로 돌아가 그 기록이 있던 달을 보여 주고 "지웠어요" 알림이 2초 보인다. [아니요] 면 고치기 화면에 그대로 남는다.
- 고치기·지우기도 기기에 저장하지 못했으면 알림 없이 장부 위쪽에 저장 실패 안내(SPEC-002)만 보인다.

### 연도

- 앱은 기본으로 올해 장부를 연다. [설정] 의 [장부 연도] 줄을 누르면 선택 창 "어느 해 장부를 볼까요?" 가 올라와 연도를 바꿔 지난 장부를 볼 수 있다(지금 연도에 체크). 고를 수 있는 연도는 장부가 있는 연도와 올해다.
- 선택 창에서 연도를 고르면 바로 장부 화면으로 돌아와 그 해의 처음 달(올해면 이번 달, 지난 연도면 12월)을 보여 준다. 지금 연도를 다시 골라도 장부로 돌아간다.
- 새 연도 장부를 처음 만들 때, 전년도 장부가 있으면 **전년도 잔액을 이월금으로 자동 채운다.** (수정 가능)

### 설정 화면

```
┌───────────────────────────────┐
│ ‹ 장부로                       │
│ 설정                           │
│ [한 달 넘게 백업하지 않았어요]   │  ← 백업 안내 띠 (필요할 때만, SPEC-002)
│ 동아리                         │  ← 묶음 제목 (작게)
│ (👥) 동아리 이름   한랑드림  ›  │
│ (🏛) 작년 이월금  370,482원  ›  │
│ (📅) 장부 연도      2026년  ›  │
│ 기록 백업                      │
│ (↗) 백업 파일 보내기         ›  │
│     마지막 백업: 2026년 9월 3일 │
│ (📁) 백업 파일 불러오기       ›  │
│     새 폰으로 옮길 때           │
│ 앱                             │  ← 홈 화면 앱으로 열었으면 묶음째 없음
│ (📱) 홈 화면에 추가           ›  │
│     기록이 더 안전해요          │
└───────────────────────────────┘
```

- 묶음 두 개(동아리 / 기록 백업)와 맨 아래 "앱" 묶음([홈 화면에 추가] 한 줄, 동작은 SPEC-002 "홈 화면 추가"). 묶음 제목은 줄 이름보다 작고 옅게. 한 줄 = 원형 아이콘 + 이름(+ 보조 줄) + 오른쪽 지금 값 + 화살표. 줄 전체가 버튼이다.
- 이월금 값은 적자면 빼기표 대신 "적자 N원".
- 줄을 누르면:
  - **동아리 이름 / 작년 이월금 → 그 값 하나만 고치는 편집 화면**(설정 목록 대신 화면 전체). 위쪽 [‹ 설정], 제목("동아리 이름 바꾸기" / "작년 이월금 바꾸기"), 입력칸(이월금은 금액 + [남았어요 | 적자였어요] 스위치), 그 아래 [저장]. 바꾼 것이 없거나 이름이 비면 [저장] 비활성(이름이 비면 "동아리 이름을 적어주세요"). [저장] 하면 "바꿨어요" 알림과 함께 설정 목록으로 돌아온다(저장하지 못하면 알림 없이 위쪽 실패 안내만, SPEC-002). [‹ 설정] 과 안드로이드 뒤로 버튼은 저장하지 않고 설정 목록으로 돌아온다(한 칸만 적는 화면이라 "버릴까요?" 는 묻지 않는다).
  - **장부 연도 → 선택 창**(위 "연도").
  - **백업 파일 보내기 / 불러오기 → 바로 그 일**(공유 화면 / 파일 고르기, SPEC-002).
  - **홈 화면에 추가 → 브라우저 설치 창**(브라우저가 설치를 제안했을 때) **또는 방법 안내 선택 창**(SPEC-002).
- 편집을 선택 창이 아닌 화면으로 한 이유: 글자 입력이 있으면 폰 키패드가 화면 아래 절반을 덮어 아래에서 올라오는 선택 창은 입력칸·[저장] 이 가려지거나 창이 밀려 올라가 흔들린다. 폰 글자 크기를 키우면 창 높이가 화면을 넘는다. 한 화면에 질문 하나와 [저장] 하나만 두면 큰 글씨 사용자가 "지금 무엇을 고치는 중인지"를 제목으로 알 수 있고, 위쪽 [‹ 설정] 으로 돌아가는 길이 장부 외 화면의 [‹ 장부로] 와 같다. 고를 것만 있는 연도는 키패드가 없어 선택 창이 더 빠르다.
- 장부가 아직 없는 연도(새 연도 시작 화면에서 [설정] 으로 온 경우)는 동아리 이름·이월금 줄 대신 "N년 장부가 아직 없어요. 장부 화면에서 시작하면 여기서 고칠 수 있어요." 안내와 [장부 연도] 줄만 보인다.

### 첫 실행

- 장부가 하나도 없으면 "동아리 이름"과 "작년 이월금" 두 칸만 묻고 시작한다.
- 동아리 이름이 비어 있으면 [시작하기] 를 누를 수 없다.
- 이월금은 금액을 양수로 적고 한 몸통 스위치 [남았어요 | 적자였어요] 중 하나를 고른다(기본 남았어요). 적자였어요면 음수로 저장한다. 숫자 키패드에서 빼기표를 찾지 않아도 되게 하기 위해서다. 설정의 이월금 수정도 같은 모양이다.
- 이월금 금액 칸은 0원도 적는 값이다: 처음 값이 0 이면 칸에 `0` 이 보이고("모르면 0으로 두고…" 안내와 같은 모양), 다 지우면 빈칸(자리표시 0), 그 상태에서 `0` 을 치면 다시 `0` 이 보인다. 앞자리 0 은 정리한다(`00` → `0`, `05` → `5`). 0원(남았어요·적자였어요 어느 쪽이든)으로 시작·저장할 수 있고, 설정에서 기존 값을 0원으로 바꿔 저장할 수도 있다. 빈칸으로 두고 시작·저장하면 0원이다 (#59).
- 장부는 있지만 고른 연도 장부가 없으면 같은 두 칸으로 새 연도 장부를 만든다. 동아리 이름은 앞선 가장 가까운 연도 장부에서, 이월금은 전년도 잔액(전년도 장부가 없으면 0)으로 채워 둔다. 이 화면 위쪽 오른쪽에 [⚙ 설정] 이 있어 새 장부를 만들지 않고 지난 장부를 골라 볼 수 있다.
- 시작 화면(첫 실행·새 연도)도 같은 부품을 쓴다: 위쪽 오른쪽 아이콘 + 글자 버튼(첫 실행 [📁 백업 불러오기], 새 연도 [⚙ 설정]), 이월금 스위치.

### 큰 글씨·쉬운 말 기준 (모든 화면 공통)

- 글자 크기는 개인 디자인 시스템 기본값을 따른다(짝수만, 14px 미만 금지): 잔액·금액 숫자 30 Bold("원"은 숫자의 60%), 화면 제목 24 Bold, 질문·카드 제목 20 Bold, 줄 이름 16 SemiBold, 본문 16, 보조 14. **폰의 글자 크기 설정을 따르도록 rem 단위**로 쓴다(어머니가 폰에서 크게 하면 같이 커짐). 글꼴은 Pretendard. 2026-10-07 사용자 피드백("글씨가 좀 크다")으로 한 단계씩 줄임.
- 글자 위계는 세 단계: 화면 제목 > 질문·카드 제목 > 보조 이름·안내. 크기와 굵기만으로 구분되고, 질문 묶음 사이 간격은 질문 ↔ 답 간격보다 확실히 넓다(선 없이 여백으로). 값은 `docs/design.md`.
- 누르는 영역 최소 56px. 아이콘만 있는 버튼 금지(아이콘 옆에 항상 글자). 예외: 장부 화면의 월 넘기기 [‹] [›] 는 기호만 보이되 화면 읽기 이름은 "이전 달"/"다음 달", 크기 56px 이상이고 가운데 달 글자와 한 줄로 읽힌다.
- 한 화면에 주 버튼은 하나.
- 용어: 회계 담당자에게 익숙한 "수입/지출", "잔액", "작년 이월금", "내역". "보고서" 대신 "월 정리", "올해 결산", 이미지 저장은 "사진으로 저장".
- 색: 개인 디자인 시스템 규칙 — 회색은 푸른 기 없는 순수 회색 계층, 화면 바탕 옅은 회색 위 흰 카드. 브랜드 색(짙은 청록)은 **화면마다 주 버튼 하나에만**(다크 모드에서도 같은 진한 청록). 고른 것·수입 금액은 청록/초록 글자, 지출 금액은 본문색 + `−`. 원색 파랑·빨강은 쓰지 않는다. 색만으로 구분하지 않는다. 값은 `docs/design.md`.
- 아이콘: 폰 앱에서 흔히 쓰는 모양만(Lucide·머티리얼 계열 선 아이콘). 항목 아이콘은 이름으로 자동: 회비·회원 → 사람들, 대관·장소 → 건물, 간식·음료 → 컵, 지원금·후원 → 선물, 이자·은행 → 은행, 꽃 → 꽃, 그 밖 → 영수증. 수입/지출 ⊕/⊖, 달 → 달력, 설정 → 톱니바퀴, 결산 → 막대그래프, 사진 저장 → 아래 화살표, 백업 보내기 → 공유, 불러오기 → 폴더, 직접 적기 → 연필.
- 좌우 여백 24px. 그림자 없음(위계는 바탕 회색과 흰 카드로).
- 텍스트 대비 WCAG AA 이상.

### 예외와 경계 상황

- 하나씩 채우기에서는 지금 질문에 답해야 다음으로 간다: 직접 적기 이름이 비면 [다음] 비활성 + "무엇인지 적어 주세요", 새 이름의 수입/지출을 안 골랐으면 [다음] 비활성 + "수입인지 지출인지 골라 주세요", 금액 0이면 [저장] 비활성 + "얼마인지 적어 주세요"(0원 내역은 없어서 내역 금액 칸은 빈칸으로 시작하고, 0 을 쳐도 빈칸이다. 0원을 적을 수 있는 이월금 칸과 다르다, #59). 안내는 버튼 바로 위. 고치기 화면은 빠진 것 중 위쪽 질문부터 한 번에 하나.
- 금액 상한 999,999,999원. 이월금은 −999,999,999 ~ 999,999,999원 정수.
- 항목 이름과 동아리 이름은 앞뒤 공백을 지우고 저장한다.
- 입력 도중 뒤로가기(안드로이드 뒤로 버튼 포함)를 누르면 입력창만 닫힌다(앱이 나가지지 않음).
- 선택 창(달·연도 등)이나 설정 편집 화면이 떠 있을 때 안드로이드 뒤로 버튼은 그것만 닫는다. "적던 내용을 버릴까요?" 보다 먼저다(창이 닫힌 뒤 한 번 더 누르면 그때 묻는다).
- 연달아 적는 중 저장에 실패하면(SPEC-002) 장부로 돌아가 저장 실패 안내를 보인다. 그 전에 저장한 내역은 그대로다.
- 내역 적기·고치기에서 처음 값과 달라진 것이 있을 때 [← 장부로] 나 뒤로 버튼을 누르면 "적던 내용을 버릴까요?" 확인([아니요] [버리기]). [버리기] 면 저장하지 않고 장부로, [아니요] 면 적던 내용 그대로 화면에 남고 다음에 뒤로 버튼을 눌러도 다시 묻는다. 확인 창이 떠 있을 때 뒤로 버튼은 [아니요] 와 같다. 달라진 것이 없으면(바꿨다가 처음 값으로 되돌린 경우 포함) 묻지 않고 바로 닫힌다. [저장]·[지우기] 뒤 장부로 돌아갈 때는 묻지 않는다.
- 고치던 기록이 화면에 있는 동안 없어지면(다른 경로로 지워짐 등) 장부로 돌아간다.

## 수용 기준

- [ ] AC-1 [+ 내역 적기] → 항목 고르기 → 금액 → [저장] → [다 적었어요] 하면 장부 화면이 그 달을 보여 주고 기록이 추가돼 있다 (자동, v2.1 연달아 적기로 [저장] 뒤 [다 적었어요] 가 붙었다)
- [ ] AC-2 기록을 추가·수정·삭제하면 잔액 = 이월금 + 수입 합 − 지출 합 으로 즉시 다시 계산된다 (자동)
- [ ] AC-3 내역 적기의 달 줄 기본값은 장부 화면에서 보고 있던 달이고, 올해 장부의 첫 화면은 이번 달을 보여 준다 (자동)
- [ ] AC-4 한 번 이상 쓴 항목 이름이 다음 입력 때 목록에 보이고, 누르면 이름과 그 항목의 수입/지출이 정해져 "지금 적는 내역" 카드에 항목 줄("대관료 · 지출")로 접히고 금액 질문으로 넘어간다. 지금 묻고 있는 값은 카드에 올리지 않는다 (자동)
- [ ] AC-5 지금 질문에 답하지 않으면 [다음]/[저장] 이 비활성이고 빠진 것을 안내한다(직접 적기 이름, 새 이름의 수입/지출, 금액) (자동)
- [ ] AC-6 기록을 눌러 수정하고 저장하면 목록과 합계에 반영된다 (자동)
- [ ] AC-7 [이 내역 지우기] → 확인 시에만 삭제된다 (자동)
- [ ] AC-8 새 연도 장부를 만들면 전년도 잔액이 이월금 기본값으로 들어간다 (자동)
- [ ] AC-9 장부 화면은 한 달씩 보이고 [‹] [›] 로 1~12월을 넘기며 그 달의 수입·지출 소계와 기록(입력 순)이 보인다. 1월에서 [‹], 12월에서 [›] 는 비활성이다 (자동)
- [ ] AC-10 금액 칸에서 폰 숫자 키패드가 뜬다 (`inputmode="numeric"`) (수동 QA)
- [ ] AC-11 390px 폭 화면에서 14px 미만 글자, 56px 미만 터치 영역이 없다 (수동 QA)
- [ ] AC-12 입력창에서 안드로이드 뒤로 버튼을 누르면 입력창만 닫힌다 (수동 QA)
- [ ] AC-13 어머니가 설명 없이 지출 1건, 수입 1건을 적을 수 있다 (수동 QA — 사용성 테스트)
- [ ] AC-14 [+ 내역 적기] 는 기록이 많아 화면을 내려도 화면 아래에 늘 보인다 (수동 QA)
- [ ] AC-15 직접 적은 이름이 처음 쓰는 이름이면 수입/지출을 묻고, 예전에 쓴 이름이면 묻지 않고 금액으로 넘어간다 (자동)
- [ ] AC-16 "지금 적는 내역" 카드의 답한 줄 [바꾸기] 를 누르면 그 값을 고칠 수 있다: [달 바꾸기] → 달 선택 창, [항목 바꾸기] → 항목 고르기로(금액 유지) (자동)
- [ ] AC-17 [+1만] [+5만] [+10만] 은 지금 금액에 더한다(상한 999,999,999) (자동)

## 기술 메모

- 화면 구조: `features/ledger`(장부·입력), `features/report`(월 정리·올해 결산), `features/settings` 로 나누고, 계산은 순수 함수(`domain/ledger.ts`)로 분리해 단위 테스트한다.
- 상태: `useLedger()` 훅이 저장소(SPEC-002)를 감싼다. 외부 상태 라이브러리는 도입하지 않는다.
- 토큰: `src/styles/tokens.css` 에 큰 글씨 기준 토큰 정의, 컴포넌트는 토큰만 사용. 공용 design-system 은 토큰 파일이 없어 CONCEPT.md 의 역할 구조·이름 체계를 옮겨 쓴다(#42, #45). 글자 크기는 rem.
- 글꼴: Pretendard 가변 굵기를 앱 파일로 포함(`src/styles/font.css`, 자주 쓰는 한글 2,780자 서브셋 645KB, `scripts/subset-font.py`), 서비스 워커가 미리 저장한다.
- 아이콘: `lucide-react`(쓴 것만 번들), `ui/Icon`. 항목 아이콘은 `domain/itemIcon.ts` 순수 함수(AC-18).
- 선택 창(`ui/BottomSheet`)·설정 편집 화면의 안드로이드 뒤로 버튼 닫기: `useScreenHistory().openSheet(이름)` 이 방문 기록 한 칸(`{ screen, sheet }`)을 쌓고, 뒤로 버튼(popstate)이면 창만 닫는다(버릴까요 확인보다 먼저). 화면에서 닫을 때(고르기·바깥·Esc·[‹ 설정])는 `closeSheet()` 가 그 칸을 `back()` 으로 되돌리고, 그 popstate 는 화면을 바꾸지 않는다. 창에서 고르자마자 장부로 갈 때(설정의 연도)는 `backToLedger()` 하나가 두 칸을 `history.go(-2)` 로 한 번에 되돌린다(`back()` 두 번은 브라우저마다 다르게 움직인다). 화면 컴포넌트는 `SheetHistory`(`sheet`·`openSheet`·`closeSheet`)만 받는다. 사용법은 훅 주석과 `docs/design.md` (#46).
- 디자인 카탈로그 `/#/dev/catalog` (개발 모드 전용).
- 연달아 적기(v2.1, #64): App 이 이번에 저장한 내역(`EntryInput[]`)을 들고, 저장할 때마다 `AddEntryForm` 을 `key`(저장 건수)로 다시 그려 처음 상태로 돌린다(달 = 마지막에 저장한 달, 버릴까요 기준도 그 달). 맨 위 카드는 `ui/SavedEntriesCard`, [다 적었어요] 는 `BottomActionBar variant="secondary"` 로 [← 장부로] 와 같은 `requestBack`. 장부로 돌아오는 길([다 적었어요]·[← 장부로]·뒤로 버튼·[버리기])이 모두 방문 기록을 되돌리는 같은 길이라, App 은 화면이 내역 적기가 아니게 된 그리기에서 저장 건수 알림·마지막 달을 맞추고 목록을 비운다. 저장에 실패하면 목록을 비우고 실패 안내만.
- 내역 적기 단계: `features/ledger/entrySteps.ts` 순수 상태 기계(단계 item → custom-name → custom-type → amount, 동작 `pick-item`·`start-custom`·`submit-custom-name`·`pick-type`·`submit-type`·`change-amount`·`change-month`·`revisit-item`). 지금 단계의 버튼·안내(`stepButton`), "적은 내용" 카드 줄(`answerRows`: 달 / 항목(이름 + 지금 묻지 않는 종류)), 버릴까요 여부(`isStepDirty`: 처음 값(보던 달만)과 다르거나 직접 적기 칸에 글자가 있음)를 함수로 계산한다. 예전에 쓴 이름의 종류는 `domain/ledger.lastUsedType` (#47).
- 키패드와 아래 고정 버튼: viewport 메타 `interactive-widget=resizes-content` 로 키패드가 뜨면 레이아웃을 줄여 `position: fixed` [저장] 이 키패드 위에 온다(크롬 108+ 기본 resizes-visual 은 고정 영역이 키패드 뒤로 숨는다). 메타를 모르는 브라우저는 `features/keyboard` 가 `visualViewport` 로 가려진 높이를 `--keyboard-inset` 으로 알려 고정 영역을 올린다(메타가 먹으면 0). 금액·이름 칸은 나타날 때 `autoFocus` (#47).
- 뒤로가기: 장부 외 화면(설정·월 정리·올해 결산)과 입력창을 열 때 `history.pushState`, `popstate` 로 장부로 돌아오기/닫기. [← 장부로] 도 `history.back()` 으로 같은 길을 쓴다. 장부로 돌아가는 중(popstate 를 기다리는 동안)에는 다시 `back()` 하지 않는다(두 번 빠지면 앱이 닫힌다).
- 닫기 전 확인: 화면이 `useScreenHistory().confirmBeforeLeave(바뀐 것 있음)` 로 알려 두면 [← 장부로](`requestBack`)와 popstate 모두 화면을 닫지 않고 확인 창을 띄운다. popstate 로 빠진 방문 기록은 그 자리에서 다시 쌓아(`pushState`) 확인 창이 떠 있는 동안이나 [아니요] 뒤에도 뒤로 버튼이 앱을 나가지 않게 하고, [버리기] 는 그 기록을 `back()` 으로 되돌려 장부로 간다. 저장·지우기 뒤에는 묻지 않는 `backToLedger` 를 쓴다.

## 결정

- 자주 쓰는 항목은 최근 사용 순 최대 6개, 모자라면 기본 항목으로 채운다. 저장하지 않고 기록에서 계산한다 (#11)
- 음수 이월금은 빼기표 입력 대신 [남았어요]/[적자였어요] 선택으로 받는다 (#12)
- 화면은 탭 없이 장부 한 화면 + 한 달씩 보기, 아래 고정 [+ 내역 적기] 하나. 수입/지출은 입력 화면에서 고른다 (기본값 없음, 항목 버튼으로 자동 선택). 디자인은 "맑은 은행 앱" 스타일 + 차분한 청록 강조색. 근거: [ADR 003](../decisions/003-month-view-layout.md)

- 설정의 이름·이월금 편집은 선택 창이 아닌 그 값 하나만 고치는 화면으로, 연도는 선택 창으로. 근거는 위 "설정 화면" (#46)
