# SPEC-001 한 줄 장부 입력

## 배경과 목표

v1 은 월별 수입 총액, 월별 지출 상세, 연간 수입내역을 따로 적고 합계를 직접 맞춰야 해서 "어디에 뭘 넣을지" 헷갈렸다. 같은 돈을 두 번 적는 구조가 원인이다.

리뉴얼 후에는 **돈이 오갈 때마다 한 줄(언제·무엇·얼마)만 적는다.** 월별 합계, 지출 상세, 수입내역, 잔액은 앱이 계산한다. 합계를 맞추는 일은 사라진다.

## 동작 정의

### 화면 구성 (탭 3개, 하단 고정)

| 탭 | 역할 |
|---|---|
| **장부** (기본) | 올해 잔액 + [돈 들어옴] [돈 나감] 버튼 + 기록 목록 |
| **보고서** | SPEC-003 |
| **설정** | 동아리명, 연도, 이월금, 백업 (SPEC-002) |

### 장부 화면

```
┌───────────────────────────────┐
│ 2026년 한랑드림               │
│ 지금 남은 돈                   │
│ 152,905원            (32px)   │
│ 들어온 돈 1,777,203 · 나간 돈 … │
├───────────────────────────────┤
│ [ + 돈 들어옴 ] [ − 돈 나감 ]  │  ← 높이 64px, 글자 포함
├───────────────────────────────┤
│ 10월                 −68,340  │  ← 월별 그룹, 최신 달이 위
│  대관료              −40,000  │
│  간식비              −28,340  │
│ 9월                 +140,806  │
│  회비               +140,806  │
└───────────────────────────────┘
```

- 기록 한 줄을 누르면 수정 화면이 열린다.
- 기록이 없으면 "아직 적은 내용이 없어요. 아래 버튼으로 시작하세요" 안내를 보여준다.

### 기록 입력 (한 화면, 위에서 아래로)

[돈 들어옴] 또는 [돈 나감] 을 누르면 전체 화면 입력창이 뜬다.

1. **몇 월인가요?** — 기본값 이번 달. 1~12월 버튼(4열 × 3행).
2. **무엇인가요?** — 자주 쓴 항목이 버튼으로 먼저 보인다(지출: 대관료, 간식비… / 수입: 회비…). 없으면 직접 입력.
   - 같은 종류(들어온 돈/나간 돈)로 쓴 이름을 최근 사용 순, 중복 없이 **최대 6개**. 지난 연도 기록도 포함한다.
   - 쓴 이름이 6개보다 적으면 뒤에 기본 항목(나간 돈: 대관료·간식비 / 들어온 돈: 회비)을 채운다. 첫 실행에도 버튼이 보이게 하기 위해서다.
3. **얼마인가요?** — 숫자 키패드가 뜨는 입력칸, 천 단위 콤마 자동, "원" 표기.
4. **[저장]** — 하단 고정 큰 버튼. 저장 후 장부로 돌아가고 "저장했어요" 알림이 2초 보인다.

- 수정 화면은 같은 모양에 값이 채워져 있고, 맨 아래 [이 기록 지우기] 텍스트 버튼이 있다.
- 지우기는 "정말 지울까요?" 확인(앱 안 다이얼로그) 후 지운다.

### 연도

- 앱은 기본으로 올해 장부를 연다. 설정에서 연도를 바꿔 지난 장부를 볼 수 있다.
- 새 연도 장부를 처음 만들 때, 전년도 장부가 있으면 **전년도 잔액을 이월금으로 자동 채운다.** (수정 가능)

### 첫 실행

- 장부가 하나도 없으면 "동아리 이름"과 "작년에서 넘어온 돈(이월금)" 두 칸만 묻고 시작한다.
- 장부는 있지만 고른 연도 장부가 없으면 같은 두 칸으로 새 연도 장부를 만든다. 동아리 이름은 앞선 가장 가까운 연도 장부에서, 이월금은 전년도 잔액(전년도 장부가 없으면 0)으로 채워 둔다.

### 큰 글씨·쉬운 말 기준 (모든 화면 공통)

- 본문 18px 이상, 금액·핵심 숫자 24px 이상, 잔액 32px. 14px 미만 금지.
- 누르는 영역 최소 56px. 기호만 있는 버튼 금지(항상 글자 포함).
- 한 화면에 주 버튼은 하나.
- 용어: "수입/지출" 대신 "들어온 돈/나간 돈", "이월금" 은 "작년에서 넘어온 돈(이월금)".
- 텍스트 대비 WCAG AA 이상. 수입은 파랑, 지출은 빨강 + 부호(+/−)를 함께 써서 색만으로 구분하지 않는다.

### 예외와 경계 상황

- 금액 0 또는 빈칸, 항목 이름 빈칸이면 [저장] 비활성 + "얼마인지 적어주세요" 안내.
- 금액 상한 999,999,999원. 이월금은 −999,999,999 ~ 999,999,999원 정수.
- 항목 이름과 동아리 이름은 앞뒤 공백을 지우고 저장한다.
- 입력 도중 뒤로가기(안드로이드 뒤로 버튼 포함)를 누르면 입력창만 닫힌다(앱이 나가지지 않음). 입력한 내용이 있으면 "적던 내용을 버릴까요?" 확인.

## 수용 기준

- [ ] AC-1 [돈 나감] → 월·항목·금액 입력 → [저장] 하면 장부 목록 해당 월에 기록이 추가된다 (자동)
- [ ] AC-2 기록을 추가·수정·삭제하면 잔액 = 이월금 + 수입 합 − 지출 합 으로 즉시 다시 계산된다 (자동)
- [ ] AC-3 월 기본값은 오늘이 속한 달이다 (자동)
- [ ] AC-4 같은 종류로 한 번 이상 쓴 항목 이름이 다음 입력 때 버튼으로 보이고, 누르면 이름 칸이 채워진다 (자동)
- [ ] AC-5 금액 또는 이름이 비어 있으면 [저장] 이 비활성이다 (자동)
- [ ] AC-6 기록을 눌러 수정하고 저장하면 목록과 합계에 반영된다 (자동)
- [ ] AC-7 [이 기록 지우기] → 확인 시에만 삭제된다 (자동)
- [ ] AC-8 새 연도 장부를 만들면 전년도 잔액이 이월금 기본값으로 들어간다 (자동)
- [ ] AC-9 장부 목록은 최신 달이 위, 월마다 소계가 보인다 (자동)
- [ ] AC-10 금액 칸에서 폰 숫자 키패드가 뜬다 (`inputmode="numeric"`) (수동 QA)
- [ ] AC-11 390px 폭 화면에서 14px 미만 글자, 56px 미만 터치 영역이 없다 (수동 QA)
- [ ] AC-12 입력창에서 안드로이드 뒤로 버튼을 누르면 입력창만 닫힌다 (수동 QA)
- [ ] AC-13 어머니가 설명 없이 지출 1건, 수입 1건을 적을 수 있다 (수동 QA — 사용성 테스트)

## 범위 밖

- 날짜(일) 단위 기록 — 보고서가 월 단위라 월만 받는다
- 항목 분류/카테고리 관리 화면
- 검색, 필터

## 기술 메모

- 화면 구조: `features/ledger`(장부·입력), `features/report`, `features/settings` 로 나누고, 계산은 순수 함수(`domain/ledger.ts`)로 분리해 단위 테스트한다.
- 상태: `useLedger()` 훅이 저장소(SPEC-002)를 감싼다. 외부 상태 라이브러리는 도입하지 않는다.
- 토큰: `src/styles/tokens.css` 에 큰 글씨 기준 토큰 정의, 컴포넌트는 토큰만 사용. (공용 design-system 은 토큰 파일 미작성이라 아직 소비하지 않음)
- 디자인 카탈로그 `/#/dev/catalog` (개발 모드 전용).
- 뒤로가기: 입력창 열 때 `history.pushState`, `popstate` 로 닫기.

## 결정

- 자주 쓰는 항목은 최근 사용 순 최대 6개, 모자라면 기본 항목으로 채운다. 저장하지 않고 기록에서 계산한다 (#11)
