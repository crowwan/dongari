# SPEC-005 여러 장부

## 배경과 목표

어머니가 동아리 회계와 같은 모양으로 **개인 가계부**도 쓰고 싶어 한다(2026-10-08 요청: "같은 형태로 여러 개 저장도 가능하면 좋겠어, 개인 가계부로도 사용하고 싶다고 하셔").

목표: 한 앱 안에 **장부를 여러 개** 두고 바꿔 가며 쓴다. 장부마다 이름·종류·연도별 기록·이월금(지금 남은 돈)이 따로이고, 화면·기능(내역 적기, 월 정리, 결산, 항목별 합계)은 지금과 같다. 지금 쓰던 장부는 그대로 첫 번째 장부가 된다.

시안: 위 링크 "여러 장부" 페이지 — **A(장부 안에서 바꾸기)** 와 "새 장부 만들기" (사용자 선택 2026-10-08, 추천안 그대로).

선행: SPEC-001(장부 화면·설정), SPEC-002(저장·백업), SPEC-003(결산).

## 동작 정의

### 용어

- **장부(book)**: 이름 하나 + 종류 하나 + 연도별 기록. 지금의 "동아리 장부" 하나가 장부 하나다.
- **종류**: `동아리·모임` / `개인 가계부`. 처음 보여 줄 기본 항목과 몇몇 문구만 다르고 기능은 같다.

### 앱을 열 때

- **마지막에 본 장부**가 바로 열린다(지금처럼 장부 화면부터). 장부가 하나뿐이면 지금과 똑같이 보인다.
- 처음 설치(장부 없음)면 지금의 첫 실행 화면 대신 **새 장부 만들기**(아래)가 뜬다. 첫 실행에는 [백업 불러오기] 도 그대로 있다.

### 장부 바꾸기 (A)

```
┌───────────────────────────────┐
│ [우리집 가계부 ▾]  [📊결산][⚙설정]│  ← 이름 + ▾ 가 한 버튼 (56px 이상)
│  2026년                        │
```

- 장부 화면 왼쪽 위 이름(+ 연도)이 버튼이 되고 이름 옆에 ▾.
- 누르면 아래에서 **"어느 장부를 볼까요?"** 선택 창(`BottomSheet`):
  - 장부마다 한 줄: 종류 아이콘(동아리 = 사람들, 가계부 = 집) + 이름 + 작은 "동아리 · 잔액 537,142원"(그 장부 올해(또는 마지막) 연도 잔액). 지금 장부는 청록 둘레 + ✓.
  - 맨 아래 **[+ 새 장부 만들기]**(점선 버튼).
  - 장부를 누르면 창이 닫히고 그 장부의 장부 화면(올해 장부면 이번 달). 바깥·뒤로 버튼은 창만 닫는다.
- 장부 목록 순서: 만든 순.

### 새 장부 만들기

1. **어떤 장부인가요?** — [동아리·모임 | 개인 가계부] 두 칸 큰 버튼(기본값 없음). 아래 "처음 보여 줄 항목만 달라요".
2. **장부 이름** — 글 칸. 종류를 고르면 비어 있을 때 예시 글자("예: 한랑드림" / "예: 우리집 가계부").
3. **지금 남은 돈**(가계부) / **작년 이월금**(동아리) — 지금의 이월금 칸과 같음(남았어요/적자였어요, 0원 가능, "모르면 0으로 두고…").
4. 아래 고정 **[만들기]**: 종류·이름이 있어야 누를 수 있다. 만들면 그 장부의 올해 장부 화면으로 가고 "새 장부를 만들었어요" 알림.

- 같은 이름의 장부가 있어도 만들 수 있다(구분은 내부 id). 이름 앞뒤 공백은 지운다.

### 종류별 차이

| | 동아리·모임 | 개인 가계부 |
|---|---|---|
| 기본 항목(써 본 적 없을 때 목록) | 대관료·간식비(지출), 회비(수입) — 지금과 같음 | 장보기·관리비·병원비(지출), 연금·용돈(수입) |
| 이월금 이름 | 작년 이월금 | 지금 남은 돈(첫 해) / 작년에서 넘어온 돈(다음 해) |
| 결산표 제목 | `<2026년 한랑드림 수입 지출 내역>` | 같은 틀, 이름만 장부 이름 |

- 항목 아이콘 규칙(SPEC-001 `itemIcon`)에 가계부 기본 항목 이름(장보기·관리비·병원비·연금·용돈)을 더한다.

### 설정

- 설정 맨 위 묶음 이름 "동아리 정보" → **"장부 정보"**: 장부 이름, 종류(바꿀 수 있음), 이월금.
- 설정 맨 아래 위험 글자형 **[이 장부 지우기]**: "‘우리집 가계부’ 장부와 기록을 모두 지울까요? 되돌릴 수 없어요" 확인([아니요] [지우기]). 지우면 남은 장부 중 첫 장부로. 장부가 하나뿐이면 버튼을 숨긴다(빈 앱이 되지 않게).

### 백업 (SPEC-002 바꿈)

- 백업 파일 하나에 **모든 장부**가 들어간다. 파일 이름은 앱 이름 기준("우리장부-백업-2026-10-08.txt").
- 불러오기는 지금처럼 **전체 바꾸기**(파일의 모든 장부로). 확인 문구에 장부 수를 적는다("장부 2개, 기록 128건으로 바꿀까요?").
- 이전 버전(장부 하나) 백업 파일도 불러올 수 있다 — 장부 하나로 읽는다.
- 30일 백업 안내는 앱 전체 기준 그대로.

### 앱 이름

- 홈 화면·탭 이름 "동아리 회계" → **"우리 장부"**(manifest `name`/`short_name`, `<title>`, og 제목). 아이콘 그림은 그대로.
- 주소(`/dongari/`)와 저장 공간(localStorage 키 이름 앞부분)은 바꾸지 않는다(이미 설치한 홈 화면 앱·기록 유지).

### 지금 기록 옮기기

- 저장 형식이 "연도별 장부 하나" → "장부 여러 개(각각 연도별)"로 바뀐다. 처음 새 버전을 열 때 지금 데이터를 **장부 하나(종류 동아리·모임, 이름 = 지금 동아리 이름)** 로 옮긴다. 기록·이월금·설정을 하나도 잃지 않는다.
- 옮기기 전에 옛 데이터를 그대로 보관(SPEC-002 마이그레이션 규칙)하고, 실패하면 읽기 전용 + 안내.

### 예외와 경계 상황

- 장부 이름이 길면 위 버튼에서 말줄임(…), 선택 창에서는 두 줄까지.
- 장부가 아주 많아도(20개 이상) 선택 창은 스크롤.
- 연도는 장부마다 따로다(가계부는 2026년만, 동아리는 2025·2026년 등). 설정의 연도 바꾸기는 지금 장부 안에서만.
- 지금 장부를 지우는 중 저장에 실패하면 아무것도 지우지 않고 저장 실패 안내.

## 수용 기준

- [ ] AC-1 지금 데이터(장부 하나)를 새 버전으로 열면 같은 이름·기록·이월금의 장부 하나(동아리·모임)로 옮겨지고 잔액·결산 숫자가 같다 (자동)
- [ ] AC-2 앱을 열면 마지막에 본 장부가 열린다 (자동)
- [ ] AC-3 장부 화면 위 이름 버튼 → "어느 장부를 볼까요?" 창에 장부마다 이름·종류·잔액이 보이고, 누르면 그 장부로 바뀐다 (자동)
- [ ] AC-4 새 장부 만들기: 종류·이름이 있어야 [만들기], 만들면 그 장부의 장부 화면으로 가고 알림 (자동)
- [ ] AC-5 개인 가계부 장부는 써 본 항목이 없을 때 가계부 기본 항목을 보여 주고, 이월금 이름이 "지금 남은 돈" 이다 (자동)
- [ ] AC-6 장부마다 기록·이월금·연도·항목 목록(자주 쓴 이름)이 섞이지 않는다 (자동)
- [ ] AC-7 [이 장부 지우기] 는 확인 뒤 그 장부만 지우고 남은 첫 장부로 간다. 장부가 하나면 버튼이 없다 (자동)
- [ ] AC-8 백업 파일에 모든 장부가 들어가고, 불러오면 모든 장부가 그대로 돌아온다. 이전 버전 백업 파일도 장부 하나로 불러온다 (자동)
- [ ] AC-9 홈 화면·탭 이름이 "우리 장부" 다 (자동: manifest·title / 수동 QA: 홈 화면 아이콘 이름)
- [ ] AC-10 이미 홈 화면에 설치한 앱이 업데이트 뒤에도 같은 아이콘으로 열리고 기록이 그대로다 (수동 QA)
- [ ] AC-11 어머니가 설명 없이 가계부 장부를 만들고 한 건 적은 뒤 동아리 장부로 돌아올 수 있다 (수동 QA — 사용성 테스트)

## 범위 밖

- 장부 사이 내역 옮기기·복사
- 장부별 백업 파일(하나만 보내기)
- 장부 순서 바꾸기, 장부 색 고르기
- 여러 장부를 합친 결산

## 기술 메모

- 저장 형식(#87): `StoredData.ledgers`(연도 → Ledger) → `books: Book[]`(`Book = { id, name, kind: 'club' | 'household', ledgers: Record<연도, Ledger>, createdAt }`, 만든 순) + `settings.lastBookId`. `schemaVersion` 3, localStorage 키는 `dongari:v2` 그대로. 근거는 [ADR 001](../decisions/001-storage.md) "v3: 장부 여러 개".
  - 이름은 장부에 하나: `Ledger.clubName` 을 없애고 `Book.name` 으로 올렸다. 연도마다 이름이 달랐으면 가장 최근 연도의 이름을 쓴다(지난 연도 결산표 제목도 장부 이름). `Ledger` 는 `{ year, carryover, entries }`.
  - v2 → v3 마이그레이션(`storage/migrate.ts`): 연도별 장부들 → 동아리·모임 장부 하나(id `book-1`, 이름 = 가장 최근 연도의 동아리 이름) + `lastBookId`. 장부가 없던 v2(첫 실행 전)는 장부 없이.
  - 옛 데이터 보관: 이전 버전 원본을 옮겨 읽을 때 `dongari:v2:schema-<버전>` 키에 그대로 둔다(같은 원본이면 다시 쓰지 않음). 보관하지 못하면 옮긴 기록은 보여 주되 저장을 막는다(`read-only`, `old-version-unpreserved`, SPEC-002 시작 상태 표). 형식이 틀린 v2 는 깨진 데이터와 같이(원본 옮기고 새로 시작).
- 지금 장부: `domain/book.currentBook(data)` = `settings.lastBookId` 장부, 없거나 지워졌으면 첫 장부. `useLedger` 는 지금 장부의 연도·기록·이월금·자주 쓴 이름만 다룬다(AC-6). 장부를 바꾸는 길은 `lastBookId` 를 바꿔 저장하는 것 하나 — 장부 고르기·만들기·지우기(#88)는 이 값을 바꾸고 App 은 보고 있는 달을 비운다.
- 첫 실행(장부 없음)의 [시작하기] 는 동아리·모임 장부 하나를 만든다(새 장부 만들기 화면은 #88).
- 백업 파일은 `StoredData` 그대로라 모든 장부가 들어간다. 이전(v2) 백업 파일은 같은 마이그레이션으로 장부 하나로 읽는다(AC-8). 불러오기 확인 문구의 연도는 모든 장부의 연도를 합친 것 — 장부 수 문구와 파일 이름은 #88.
- 앱 이름 변경은 `pwaOptions`·`index.html`·백업 파일 이름. 서비스 워커·manifest `id` 는 그대로(설치 앱 유지).
