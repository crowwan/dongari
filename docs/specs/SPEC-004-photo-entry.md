# SPEC-004 적어 둔 글로 한 번에 적기

## 배경과 목표

어머니는 수입·지출을 먼저 공책(수기 장부)에 적어 둔다. 이걸 폰에서 한 건씩 다시 치는 게 가장 큰 일이다.

최종 목표는 **장부 사진을 올리면 앱이 글씨를 읽어 내역 초안을 만들고, 어머니는 이상한 값만 고쳐 한 번에 넣는 것**이다. 기술 검토(2026-10-07, ADR 002 갱신) 결과 손글씨 인식 엔진은 실제 장부 사진으로 비교해 본 뒤에 고르기로 하고, 이 스펙은 **어떤 엔진을 쓰든 똑같이 필요한 뒷부분**을 먼저 만든다.

- **이 스펙(1단계)**: 글(여러 줄) → 내역 초안으로 정리 → **확인 화면**에서 고치고 → 한 번에 장부에 넣기. 글은 붙여넣기나 다른 앱에서 공유로 받는다. 갤럭시 갤러리의 "텍스트 추출"로 장부 사진의 글자를 복사·공유하면 이것만으로 사진 → 내역이 된다(모델 없음).
- **2단계(별도 스펙, 엔진 비교 후)**: 앱 안에서 사진을 바로 읽는 인식기. 1단계의 정리 규칙과 확인 화면을 그대로 쓴다.

확인하기 전에는 아무것도 장부에 들어가지 않는다.

선행: SPEC-001 (기록 모델·내역 고치기 화면), SPEC-002 (저장).

## 동작 정의

### 들어오는 길

1. **붙여넣기**: 내역 적기 첫 질문(무엇인가요?) 화면 맨 아래 보조 줄 **[여러 건 한 번에 적기]**. 누르면 "적어 둔 글을 붙여 넣어 주세요" 큰 글 칸(여러 줄) + 안내 "갤러리에서 장부 사진을 열고 '텍스트 추출'로 복사하면 편해요" + [정리하기]. 글 칸이 비어 있으면 [정리하기] 비활성.
2. **공유 받기**: 홈 화면에 추가한 앱은 폰 공유 목록에 "동아리 회계"로 보인다(Web Share Target, 글만). 갤러리 텍스트 추출 → 공유 → 동아리 회계를 고르면 앱이 열리고 받은 글로 바로 확인 화면을 띄운다. 장부가 아직 없으면(첫 실행) 받은 글은 버리고 장부 시작 화면을 띄운다.

### 확인 화면

```
┌───────────────────────────────┐
│ ← 7건을 찾았어요               │
│   노란 줄은 꼭 확인해 주세요    │
├───────────────────────────────┤
│ ☑ (🏢) 대관료 · 10월   −40,000 │
│ ☑ (🍪) 간식비 · 10월   −28,340 │
│ ☑ (👥) 회비 · ?월     +140,000 │  ← 노란 바탕 + "몇 월인지 확인"
│ ☑ (?) 꽃다발 · 10월     30,000 │  ← 노란 바탕 + "수입인지 지출인지 확인"
│ ☐ (🏢) 대관료 · 10월   −40,000 │  ← 흐리게 + "이미 있는 내역 같아요"
│ [+ 빠진 줄 직접 적기]          │
├───────────────────────────────┤
│ [ 6건 장부에 넣기 ]            │  ← 아래 고정 주 버튼
└───────────────────────────────┘
```

- 각 줄: 체크(넣을지) · 항목 아이콘 · 이름 · 월 · 부호 붙은 금액. 장부 화면 내역 줄과 같은 모양에 체크와 노란 표시만 더한다.
- 줄을 누르면 SPEC-001 **내역 고치기** 화면이 뜬다(빠진 값은 하나씩 채우기 순서대로 묻는다). 저장하면 확인 화면으로 돌아오고 그 줄의 노란 표시가 사라진다. 고치기 화면의 [지우기]는 그 줄을 목록에서 뺀다.
- **노란 표시(확인 필요)** 조건:
  - 월을 찾지 못함 (월 칸 "?월", 기본값 없음 — 고쳐야 넣을 수 있다)
  - 수입/지출을 정하지 못함 (부호 없이 금액만)
  - 이름이 장부에 없던 새 이름
  - 금액이 1,000,000원 초과
- 월 또는 수입/지출이 빈 줄은 체크해도 넣을 수 없다. [N건 장부에 넣기]를 누르면 "몇 월인지(수입인지 지출인지) 정하지 않은 줄이 2개 있어요" 알림과 함께 첫 줄로 스크롤한다.
- 그 밖의 노란 줄(새 이름, 큰 금액)은 그대로 넣을 수 있다. 넣기 전 한 번 묻는다: "확인 안 한 줄이 2개 있어요. 그래도 넣을까요?"
- **이미 있는 내역**: 이번 장부에 같은 월·구분·이름·금액의 내역이 있으면 체크 해제 + "이미 있는 내역 같아요". 체크하면 넣을 수 있다.
- [+ 빠진 줄 직접 적기]는 SPEC-001 내역 적기 흐름으로 한 줄을 만들어 목록 맨 아래에 붙인다(장부에 바로 넣지 않는다).
- 버튼 문구의 N 은 넣을 수 있는 체크된 줄 수. 0건이면 버튼 비활성.
- 넣으면 장부 화면(넣은 내역 중 가장 이른 달)으로 돌아가 "6건을 넣었어요 [되돌리기]" 알림을 5초 보인다. 되돌리기는 방금 넣은 묶음(`batchId`) 전체를 지운다.
- 뒤로 버튼(안드로이드 포함) → "정리한 내용을 버릴까요?" 확인. SPEC-001 적던 내용 버리기와 같은 규칙.

### 정리 규칙 (글 → 내역 초안)

순수 함수 `parseLedgerText(text, context)` 가 맡는다. `context` 는 장부의 연도·이미 쓴 이름과 그 수입/지출, 오늘 날짜.

- 글을 줄 단위로 읽는다. 앞뒤 공백·빈 줄은 무시.
- **월**:
  - 줄 안의 날짜 `10/15`, `10.15`, `10-15`, `10월 15일`, `10월` → 월만 쓴다.
  - 금액 없이 월만 있는 줄(예: `10월`, `<10월>`)은 **머리글**: 다음 머리글이 나올 때까지 아래 줄들에 그 월을 쓴다.
  - 날짜도 머리글도 없으면 월은 비운다(노란 표시).
- **금액**: 줄에서 숫자 묶음을 찾는다. `,` `.`(천 단위) `원` `₩` 은 무시. 날짜로 쓴 숫자는 금액이 아니다. 숫자 묶음이 여럿이면 가장 오른쪽 것. 금액이 없거나 0 이면 그 줄은 내역이 아니다.
- **수입/지출**:
  - 금액 앞 `+` → 수입, `-` `−` `△` → 지출.
  - 부호가 없으면 이름으로: 장부에 이미 쓴 이름이면 그 이름의 수입/지출, 항목 목록(SPEC-001 기본 항목)에 있으면 그 항목의 구분.
  - 둘 다 아니면 비운다(노란 표시).
- **이름**: 날짜·금액·부호·괄호를 뺀 나머지 글. 이미 쓴 이름·기본 항목과 띄어쓰기 무시하고 같으면 그 이름으로 맞춘다. 글자 하나 차이(예: `대관로` → `대관료`)는 맞추되 노란 표시(이름 확인). 이름이 비면 그 줄은 내역이 아니다.
- **내역이 아닌 줄**: `합계` `소계` `총` `잔액` `이월` `계` 로 시작하거나 그 말만 있는 줄은 만들지 않는다.
- 읽을 수 없는 줄은 만들지 않는다(지어내지 않는다). 버린 줄 수는 확인 화면 위에 "읽지 못한 줄 2개는 뺐어요"로 알린다.
- 한 번에 최대 100줄. 넘으면 앞 100줄만 정리하고 알린다.

### 예외와 경계 상황

- 정리한 내역이 하나도 없으면 "내역을 찾지 못했어요. 한 줄에 '이름 금액'처럼 적혀 있는지 봐 주세요" + 글 칸으로 돌아가기(글은 그대로).
- 연도는 지금 보고 있는 장부 연도. 다른 연도의 내역은 이 스펙에서 다루지 않는다.
- 공유로 받은 글이 비어 있거나 글이 아닌 것(사진 파일 등)이면 붙여넣기 화면을 빈 칸으로 띄운다.
- 받은 글·정리 결과는 저장하지 않는다. 확인 화면을 떠나면 버린다.
- 읽기 전용 상태(SPEC-002 저장 문제)면 [여러 건 한 번에 적기]도 다른 적기 버튼처럼 막는다.

## 수용 기준

- [ ] AC-1 정리 결과는 확인 화면에만 보이고, [장부에 넣기] 전에는 장부·잔액이 바뀌지 않는다 (자동)
- [ ] AC-2 체크되고 월·구분이 정해진 줄만 장부에 들어가고, 넣은 건수가 버튼 문구와 같다 (자동)
- [ ] AC-3 월 없음, 구분 없음, 새 이름, 1,000,000원 초과 줄이 노란 표시된다 (자동)
- [ ] AC-4 장부에 같은 월·구분·이름·금액 내역이 있으면 그 줄은 체크 해제 + "이미 있는 내역 같아요" 로 보인다 (자동)
- [ ] AC-5 줄을 눌러 고치면 값이 반영되고 노란 표시가 사라진다 (자동)
- [ ] AC-6 월·구분이 빈 줄이 체크돼 있으면 넣지 못하고 알린다. 그 밖의 노란 줄이 남은 채 넣으려 하면 한 번 묻는다 (자동)
- [ ] AC-7 [되돌리기] 를 누르면 방금 넣은 묶음만 지워진다 (자동)
- [ ] AC-8 "10월" 머리글 아래 줄들에 월 10 이 적용되고, 합계·소계·잔액 줄은 내역이 되지 않는다 (자동)
- [ ] AC-9 날짜(`10/15`, `10월 15일`)의 숫자는 금액으로 읽지 않고, `+`/`-` 부호와 이미 쓴 이름으로 수입/지출이 정해진다 (자동)
- [ ] AC-10 정리한 내역이 없으면 장부를 바꾸지 않고 안내와 함께 글 칸으로 돌아간다 (자동)
- [ ] AC-11 정리 중 네트워크 요청이 없다 (자동)
- [ ] AC-12 홈 화면에 추가한 앱이 갤럭시 공유 목록에 보이고, 갤러리 "텍스트 추출" 글을 공유하면 확인 화면이 뜬다 (수동 QA)
- [ ] AC-13 어머니 장부 사진을 갤러리 "텍스트 추출"로 옮겼을 때 금액·월이 맞게 정리되는 비율을 기록한다 (기준선 측정, 수동 QA)
- [ ] AC-14 어머니가 장부 한 쪽을 공유해 이상한 줄을 고치고 장부에 넣을 수 있다 (수동 QA — 사용성 테스트)

## 범위 밖

- 앱 안에서 사진을 바로 읽는 인식기 (2단계, 엔진 비교 스파이크 후 별도 스펙)
- 여러 연도에 걸친 내역 한 번에 넣기
- 영수증·카드 내역 캡처 인식
- 사진·원문 글을 내역에 붙여 보관

## 기술 메모

- 정리 규칙 `parseLedgerText` 는 `src/domain/` 순수 함수. 결과 줄 형식: `{ month?, type?, name, amount, flags: ('month' | 'type' | 'new-name' | 'name-guess' | 'large-amount' | 'duplicate')[] }`.
- 2단계 인식기는 "사진 → 글(줄 목록)"까지만 하고 같은 정리 규칙에 넘긴다. 그래서 인식 계층 인터페이스는 `(photo) => Promise<string>` 정도로 둔다 — 2단계 스펙에서 정함.
- 공유 받기: `manifest.share_target` (`action: <base>/share`, `method: GET`, `params: { text, title }`). GET 이라 서비스 워커 처리 없이 정적 호스팅(GitHub Pages)에서 된다. 앱은 시작할 때 주소의 `text` 를 읽고 주소에서 지운다(`history.replaceState`). 공유 목록에 뜨는 건 크롬이 설치한 앱(WebAPK)이 확실하고, 삼성 인터넷 설치 앱은 수동 QA 에서 확인.
- 묶음 넣기는 기존 `batchId` 로 묶는다(되돌리기). 저장은 한 번에(여러 번 save 하지 않는다).

## 열린 질문

- 갤러리 "텍스트 추출"이 어머니 손글씨를 얼마나 읽고, 줄 구조(이름과 금액이 한 줄)를 지키는지 — 결정: 장부 사진 확보 후 실험 페이지(`/lab`)에서 측정. 줄 구조가 깨지면 정리 규칙을 고친다.
- 1단계로 충분하면 2단계(앱 안 인식기)를 할지 — 결정: AC-13 측정 후
