# SPEC-003 보고서 바로 보내기

## 배경과 목표

v1 은 보고서를 PNG 로 '다운로드'해서 어머니가 갤러리·파일 앱에서 찾아 카톡에 다시 올려야 했다.

목표: 보고서 모양은 v1 과 **똑같이 유지**하고, 버튼 하나로 카톡 공유 화면까지 간다.

## 동작 정의

### 보고서 탭

1. 상단에 보고서 미리보기(v1 `PLANS.md` 6장 양식 그대로: 월별 수입·지출 표 + 이월금·잔액, 좌우 분할 지출내역 표, 수입내역 항목별 합계).
2. 미리보기는 손가락으로 확대해 볼 수 있다.
3. 하단 고정 큰 버튼 **[카톡 등으로 보내기]** — 보고서 이미지를 만들어 공유 화면을 연다.
4. 그 아래 텍스트 버튼 [사진으로 저장] — 공유를 지원하지 않는 환경이거나 저장만 원할 때 다운로드.
5. 이미지를 만드는 동안 버튼에 "만드는 중…" 을 표시하고 중복 누름을 막는다.

### 계산 규칙 (기록 → 보고서)

- 월별 수입/지출 = 해당 월 기록 합.
- 지출내역 표 = 월별 지출 기록을 입력 순서대로. 1~6월 왼쪽, 7~12월 오른쪽, 좌우 행 수 맞춤.
- 수입내역 = 수입 기록을 **이름별로 합산**, 처음 등장한 순서대로.
- 잔액 = 이월금 + 연간 수입 − 연간 지출.

### 예외와 경계 상황

- 기록이 하나도 없으면 미리보기 대신 "적은 내용이 있어야 보고서가 만들어져요" 안내, 버튼 비활성.
- 공유를 사용자가 취소하면 아무 안내 없이 원래 화면.

## 수용 기준

- [ ] AC-1 기록에서 계산한 월별 수입·지출, 연간 합계, 잔액이 보고서에 표시된다 (자동)
- [ ] AC-2 같은 이름의 수입 기록은 수입내역에서 한 줄로 합쳐진다 (자동)
- [ ] AC-3 v1 샘플 데이터와 같은 내용을 입력하면 v1 과 같은 숫자의 보고서가 나온다 (자동)
- [ ] AC-4 지출내역 표의 좌우(1~6월 / 7~12월) 행 수가 같다 (자동)
- [ ] AC-5 기록이 없으면 보내기 버튼이 비활성이다 (자동)
- [ ] AC-6 갤럭시 삼성 인터넷·크롬에서 [카톡 등으로 보내기] → 공유 화면 → 카톡으로 이미지가 전송된다 (수동 QA)
- [ ] AC-7 생성된 이미지가 v1 양식과 같아 보인다 (변경 전/후 이미지 비교) (수동 QA)

## 범위 밖

- PDF 출력, 인쇄 레이아웃
- 보고서 양식 편집

## 기술 메모

- 보고서 컴포넌트는 v1 `components/report/*` 를 재사용하되 입력을 `MonthlyData[]` 대신 계산된 `ReportModel` 로 바꾼다. 계산은 `domain/report.ts` 순수 함수.
- 이미지: html2canvas 유지(oklch 회피용 인라인 스타일 유지). `canvas.toBlob` → `File` → `navigator.share({ files })`.
- `navigator.share` 는 사용자 누름 직후(일시적 활성화)에만 호출되므로, 이미지 생성이 길면 실패할 수 있다 → 탭 진입 시 미리 생성해 두는 방식 검토 — 결정: 기술 검증 후 (첫 이슈)

## 열린 질문

- 삼성 인터넷에서 파일 공유(`canShare({ files })`)와 공유 제스처 제한 동작 — 결정: 기술 검증 후 (첫 이슈)
