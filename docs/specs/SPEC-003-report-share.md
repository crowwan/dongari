# SPEC-003 월 정리와 올해 결산

## 배경과 목표

v1 은 보고서를 PNG 로 '다운로드'해서 어머니가 갤러리·파일 앱에서 찾아 카톡에 다시 올려야 했다.

목표:
- 달마다 그 달 내역을 한 화면으로 정리해 보고, 사진으로 바로 보낸다 (월 정리).
- 1년치는 v1 연말 양식과 **똑같은 모양**으로 보고, 사진으로 바로 보낸다 (올해 결산).
- 화면에서 "보고서" 라는 말은 쓰지 않는다.

## 동작 정의

### 월 정리 (장부 화면 [N월 정리 보기])

```
┌───────────────────────────────┐
│ ← 장부로                       │
│ 2026년 9월 정리                 │
│ ┌ 수입 ───────────────────────┐│
│ │ 회비              140,000원 ││
│ │ 수입 합계          140,000원 ││
│ └─────────────────────────────┘│
│ ┌ 지출 ───────────────────────┐│
│ │ 대관료              40,000원 ││
│ │ 간식비              58,280원 ││
│ │ 지출 합계           98,280원 ││
│ └─────────────────────────────┘│
│ ┌─────────────────────────────┐│
│ │ 8월까지 잔액     1,124,473원 ││
│ │ 9월 수입 − 지출    +41,720원 ││
│ │ 9월 말 잔액      1,166,193원 ││
│ └─────────────────────────────┘│
├───────────────────────────────┤
│      [ ⬇ 사진으로 저장 ]        │
└───────────────────────────────┘
```

- 카드 셋(수입 / 지출 / 잔액, 시안 ③ — ADR 004). 수입·지출 카드는 제목(카드 제목 크기) 아래 "이름 ··· 금액" 줄, 합계 줄만 위 구분선 + 굵게. 수입 합계 금액은 수입 금액색. 잔액 카드는 제목 없이 세 줄이고 월말 잔액 금액만 한 단계 크게.
- 수입·지출 내역은 그 달 기록을 날짜순(같은 날은 적은 순, 날짜 없는 예전 기록은 맨 뒤)으로, 이름이 같아도 합치지 않는다 (장부와 같게). 줄 이름 앞에 "7일"(날짜 없으면 생략) (v2.2).
- 전달까지 잔액 = 이월금 + 1월~전달 수입 − 1월~전달 지출. 1월이면 "작년 이월금" 으로 표시. 작년이 적자(이월금 음수)면 "작년 적자 N원" (장부 잔액 카드의 "작년 적자 … 포함" 과 같은 말).
- 그 달 수입 − 지출은 부호를 붙인다 (`+41,720원`, `−40,000원`, 0 은 부호 없음). 잔액이 적자면 `−` 가 붙는다.
- 수입 또는 지출 기록이 없는 쪽 묶음은 합계 없이 "없어요" 한 줄.
- 그 달 기록이 없으면 이 화면으로 들어오는 버튼이 없다 (SPEC-001).

### 올해 결산 (장부 화면 위쪽 [📊 결산])

1. v1 `PLANS.md` 6장 양식: 월별 수입·지출 표 + 이월금·잔액, 좌우 분할 지출내역 표, 그리고 **항목별 합계 표**(v2.3 — v1 의 "◈ 수입내역" 목록을 바꿈).
   - 항목별 합계 표: 제목 `<2026년 한랑드림 항목별 합계>`, 위 월별 표와 같은 선·머리 칸 모양. 머리 줄 [수 입 | 지 출] 이 각각 두 칸(이름·금액)을 차지하고, 줄마다 왼쪽에 수입 항목, 오른쪽에 지출 항목. 짧은 쪽은 빈 칸. 맨 아래 "계" 줄(수입 합계 / 지출 합계, 머리 칸 바탕). 금액 칸은 같은 폭, 남은 폭을 수입·지출 이름 칸이 반씩 나누고 긴 이름은 낱말 단위로 줄을 바꾼다(한쪽 긴 이름이 다른 쪽 칸을 줄이지 않게).
   - v1 양식 맨 아래 "2026년 지출 합계 ₩…" 줄은 지출내역 표의 합계라 지출내역 표 바로 아래로 옮겨 남긴다(v2.3, 항목별 합계 표 아래에 두면 그 표의 줄처럼 읽힌다). v1 의 수입내역 아래 "₩ 수입 합계" 줄은 표의 "계" 가 대신한다.
   - 시안 https://claude.ai/artifact/8S8y4GuLU5xkVkHTRPxt7M "항목별 합계" 결산표 B.
2. 화면 폭에 맞게 줄여 보여 주고 손가락으로 확대해 볼 수 있다.
   - 양식은 v1 과 같은 360px 고정 폭으로 그리고, 화면에서는 `transform: scale(화면 폭 ÷ 360)` 으로 폭에 맞춘다 (가로 스크롤 없음). 사진은 줄이지 않은 360px 그대로 2배로 그린다.
   - 확대는 브라우저 기본 두 손가락 확대 (viewport 에 확대를 막는 설정이 없다). 양식 위에 "두 손가락으로 벌리면 크게 볼 수 있어요" 한 줄.
   - 지출내역 표의 달 칸은 6.2 그림처럼 "1월" 로 쓰고, 6.3 대로 달이 바뀌는 줄에만 가로 선을 긋는다. v1 의 두 버그(짝이 아니라 왼쪽·오른쪽 전체 줄 수만 맞춰 표가 잘림, "지출 합계" 연도가 올해 날짜)는 따라 하지 않는다.
3. **[결산표 | 항목별 합계]** 전환(v2.3): 결산 화면 제목 아래 두 칸 전환 버튼(`SegmentedControl`). 처음은 [결산표]. [항목별 합계] 를 고르면 양식 대신
   - **수입** 카드와 **지출** 카드가 위아래로. 카드 머리 = "수입"/"지출" + 그해 합계(수입은 수입 금액색).
   - 줄 = 이름 + 작은 "N건" + 오른쪽 금액, 아래 얇은 비율 막대(그해 수입/지출 합계 대비, 수입 옅은 청록·지출 회색). 누르는 곳 없음.
   - 한쪽 기록이 없으면 그 카드에 "올해 적은 수입(지출)이 없어요".
   - [사진으로 저장] 은 [결산표] 일 때만 보인다(사진은 결산표만).
   - 시안 "항목별 합계" 앱 A.

   > v2.6 보강(draft, 아래)에서 이 전환이 **[단톡방용 요약 | 결산표(제출용)]** 으로 바뀐다. 항목별 합계 카드는 단톡방용 요약 안으로 들어간다.
4. 기록이 하나도 없으면 양식 대신 "적은 내역이 있어야 결산을 만들 수 있어요" 안내, [사진으로 저장] 비활성.

### 사진으로 저장 (두 화면 공통)

- 하단 고정 큰 버튼 **[⬇ 사진으로 저장]** (내려받기 아이콘 + 글자) — 화면의 정리/결산 영역을 PNG 이미지로 만들어 폰에 내려받는다. 갤럭시에서는 갤러리의 "Download" 앨범에서 보인다. 카톡 등으로 보내는 건 어머니가 갤러리에서 직접 한다.
- 파일 이름: `동아리회계-2026년-9월-정리.png`, `동아리회계-2026년-결산.png`.
- 이미지를 만드는 동안 버튼이 "만드는 중…" 으로 바뀌고 누를 수 없다(중복 누름 방지). 다 되면 "사진을 저장했어요. 갤러리의 Download 앨범에서 볼 수 있어요" 알림, 만들거나 내려받다 실패하면 "사진을 만들지 못했어요. 다시 눌러 주세요" 알림. 긴 알림은 글자 수만큼 오래 보인다(글자당 0.12초, 최소 2초).
- **아이폰·아이패드(iOS, #58)**: 내려받기(`<a download>`)는 사진 앱이 아니라 파일 앱의 다운로드 폴더로 가므로, 사진을 PNG 파일로 공유 시트(Web Share `navigator.share({ files })`)에 넘긴다. 어머니가 시트에서 "이미지 저장"을 고르면 사진 앱에 들어간다.
  - iOS 판별: UA 에 iPhone·iPad·iPod, 또는 맥 UA 인데 터치가 되는 기기(iPadOS 사파리). 갤럭시(안드로이드)는 위처럼 내려받기 그대로.
  - 버튼 위 안내: "누른 다음 '이미지 저장'을 고르면 사진 앱에 들어가요".
  - 시트에서 고르면 "사진 앱에 저장했어요" 알림. 시트를 그냥 닫으면 알림 없이 원래대로.
  - 공유 시트를 못 쓰면(파일 공유 미지원 등) 내려받고 "사진을 저장했어요. 파일 앱의 다운로드 폴더에서 볼 수 있어요" 알림.
  - 공유 시트는 누른 순간(사용자 활성화, WebKit 은 약 5초) 안에서만 열린다. 사진을 만드는 데 그보다 오래 걸려 거부(NotAllowedError)되면, 만든 사진을 들고 버튼을 **[사진 앱에 저장]** 으로 바꾸고 위에 "사진이 준비됐어요. 한 번 더 눌러 주세요" 를 띄운다. 누르면 다시 만들지 않고 바로 시트를 연다. 그래도 거부되면 내려받는다.
- 카톡 등으로 바로 보내는 앱 안 공유는 v2.0 에서 쓰지 않는다 (2026-10-06 결정: 갤러리 저장만으로 충분). 아이폰 공유 시트는 사진 앱에 넣는 길로만 안내한다.
  > v2.6 보강(draft)에서 이 결정을 뒤집는다: 정리·결산 아래 주 버튼이 폰 공유 창을 연다. 이유는 아래 "v2.6 보강" 과 [ADR 007](../decisions/007-report-share-summary.md).
- 이미지는 화면 테마와 상관없이 흰 바탕(단톡방에서 읽기 쉽게).
  - 월 정리: 사진으로 그리는 복사본에만 라이트 테마(`data-theme="light"`)를 고정하고 흰 바탕 + 카드 둘레 옅은 선 + 가장자리 여백. 화면 모양(토큰)을 그대로 쓴다. 단 사진에서는 자간과 숫자 폭 맞춤을 끈다 (html2canvas 가 이 둘을 읽지 못해 "1 40,000" 처럼 숫자가 벌어진다).
  - 올해 결산: 양식 자체가 흰 종이·검정 글자 인라인 hex 라 테마와 무관하다.

### 계산 규칙 (기록 → 결산)

- 월별 수입/지출 = 해당 월 기록 합.
- 지출내역 표 = 월별 지출 기록을 장부와 같은 순서(날짜순)로. 양식에 날짜 칸은 넣지 않는다(v2.2 사용자 결정). 1~6월 왼쪽, 7~12월 오른쪽에 두고 1월↔7월 … 6월↔12월 짝마다 행 수를 맞춘다 (v1 6.3). 짝 높이 = 두 달 중 많은 지출 수(없으면 1줄), 짧은 쪽은 빈 줄로 채우고 달 칸은 짝 높이만큼 합친다.
- 항목별 합계(결산표 표·앱 화면 같음) = 수입·지출 각각 기록을 **이름이 똑같은 것끼리 합산**(띄어쓰기·괄호까지 같아야 한 줄. "간식비(8월)" 과 "간식비" 는 다른 줄), 금액 큰 순(같으면 그해 처음 나온 순 — 이른 달, 같은 달은 장부 날짜순으로 처음 나온 항목. 적은 순서가 아니다). 건수 = 합친 기록 수. 비율(그쪽 연간 합계 대비)은 화면 막대에만.
- 잔액 = 이월금 + 연간 수입 − 연간 지출.

     - 세 줄 "수입 +N원" / "지출 −N원" / "잔액 N원": 이름은 18 SemiBold, 금액은 24 Bold 한 덩어리(줄바꿈 없음). 수입 금액은 수입 금액색, 지출은 지출 금액색.
     - 잔액 줄은 위에 가는 구분선을 긋고 금액을 30 Bold 로 한 단계 크게. 적자면 `−`.
     - 그 아래 보조 줄(14)은 장부 잔액 카드 보조 줄과 같은 말이다(SPEC-001·SPEC-005 종류별 이월금 문구, 0원이면 숨김).
  2. "수입 항목별" 카드, 3. "지출 항목별" 카드
     - 머리 = 이름 + 그해 합계. 줄은 지금 [항목별 합계] 카드(`ItemTotalsCards`, v2.3)와 같다: 이름 · "N건" · 금액 + 비율 막대, 같은 이름끼리 합산, 금액 큰 순(본문 "계산 규칙").
     - 이름과 금액이 한 줄에 안 들어가면 금액이 이름 아래 줄로 내려간다(SPEC-001 v2.6 보강 장부 줄과 같은 규칙: 금액 줄바꿈 없음, 이름은 낱말 단위).
     - 한쪽 기록이 없으면 그 카드에 "올해 적은 수입(지출)이 없어요".
  - 카드 아래 보조 글 "이 화면 그대로 사진 한 장이 돼요"(가운데, 사진에는 넣지 않음).
- **결산표(제출용)**: 지금 결산표(v1 양식 + v2.3 항목별 합계 표) 그대로다. 모양·사진·AC-3·4·7 은 바뀌지 않는다. 동아리 제출용 종이라서 바꾸지 않는다.
  - 점검 03 의 axe 지적 하나만 고친다: 월별 수입·지출 표 왼쪽 위 빈 머리 칸에 화면 읽기 전용 이름 "월" 을 단다(보이는 모양은 그대로, 사진도 그대로).
- 기록이 하나도 없으면 지금처럼 전환 버튼 없이 "적은 내역이 있어야 결산을 만들 수 있어요" 안내. 아래 두 버튼은 비활성.
- 전환은 지금처럼 화면 안 상태라 방문 기록에 쌓지 않는다.

### 아래 고정 버튼 둘: 보내기(주) + 사진으로 저장(보조)

- 올해 결산(두 쪽 모두)과 **월 정리**에 같은 고정 영역을 둔다(시안 결정 "월 정리에도 넣기").
  - 왼쪽: 보조 [⬇ 사진으로 저장](옅은 청록 면, 글자 폭만큼).
  - 오른쪽: 주 [↗ 사진 보내기](청록 채움, 남은 폭을 다 씀).
  - 글자를 키워 한 줄에 안 들어가면 주 버튼이 위, 보조가 아래로 쌓인다(둘 다 폭 채움).
- **주 버튼 이름은 열린 질문**이다.
  - 버튼은 카카오 전용이 아니라 폰 공유 창을 연다. 공유 창에서 카톡·문자·밴드·Quick Share 등을 고른다.
  - 후보: [사진 보내기](추천) / [카톡으로 보내기](시안 추천) / [공유하기].
  - 이 문서에서는 가칭 [사진 보내기] 로 쓴다.
  - 추천 이유: 무엇을(사진) 하는지(보내기)가 쉬운 말로 보인다. "카톡으로" 는 문자·밴드를 고를 수 있다는 걸 가리고, "공유하기" 는 처음 쓰는 분께 낯선 말이다.
  - 카톡 길은 첫 사용 말풍선 3 문구 "카톡·문자로 보낼 수 있어요"(SPEC-008)로 알린다.
- 무엇을 보내나: 지금 보고 있는 것.
  - 단톡방용 요약 → 요약 사진.
  - 결산표(제출용) → 지금과 같은 결산표 사진.
  - 월 정리 → 지금과 같은 월 정리 사진.
- [사진 보내기]: 사진을 만들고(버튼 "만드는 중…", 중복 누름 막음) PNG 파일 하나를 폰 공유 창(`navigator.share({ files })`)에 넘긴다. **갤럭시도 공유 창을 쓴다**(지금은 아이폰만).
  - 공유 창을 그냥 닫으면(`AbortError`) 알림 없이 원래대로.
  - 아래 세 가지는 **#114 기술 검증 결과 후 확정**:
    - 공유 창에서 앱을 고른 뒤 알림을 띄울지. 제안: 알림 없음. 공유 창이 닫혔다고 보낸 것은 아니다.
    - 사진을 만드는 데 걸린 시간 때문에 누른 순간(사용자 활성화)이 지나 거부되면(`NotAllowedError`) 어떻게 할지. 제안: 아이폰 [사진 앱에 저장] 처럼, 만든 사진을 들고 버튼을 **[한 번 더 눌러 보내기]** 로 바꾸고, 위에 "사진이 준비됐어요. 한 번 더 눌러 주세요" 를 띄운다. 다시 거부되면 내려받는다. 사진을 미리 만들어 두는 방법도 #114 에서 본다.
    - 공유 창을 못 쓰는 폰(파일 공유 미지원)의 대체. 제안: 내려받고 "사진을 저장했어요. 카톡에서 갤러리의 Download 앨범 사진을 골라 보내 주세요" 알림. 글자 수만큼 오래, 본문 "사진으로 저장" 규칙.
  - 사진과 함께 글(`text`·`title`, 예: "2026년 한랑드림 결산")을 같이 넘길지 — #114 결과 후 확정.
- [사진으로 저장]: 지금 동작 그대로다(갤럭시 내려받기 Download 앨범, 아이폰 공유 시트 "이미지 저장"). 시안 결정 "보조 버튼으로 남김". 공유 창이 안 되는 폰과 갤러리에 모아 두고 싶은 분을 위한 길이다.
- 아이폰 버튼 위 안내 "누른 다음 '이미지 저장'을 고르면 사진 앱에 들어가요" 는 [사진으로 저장] 에 대한 말이라 그대로 둔다.
- 사진 파일 이름
  - 요약: `우리장부-2026년-결산-요약.png`(새).
  - 결산표: 지금 `우리장부-2026년-결산.png` 그대로.
  - 월 정리: 지금 `우리장부-2026년-9월-정리.png` 그대로.

### 요약 사진 모양

- 월 정리 사진 규칙(본문 "사진으로 저장")을 그대로 따른다.
  - 화면 모양(토큰)을 쓰고, 사진으로 그리는 복사본에만 라이트 테마를 고정한다.
  - 흰 바탕 + 카드 둘레 옅은 선 + 가장자리 여백.
  - 자간과 숫자 폭 맞춤은 끈다.
- 사진에 들어가는 것은 카드 셋뿐이다. 전환 버튼, "이 화면 그대로…", 아래 버튼은 넣지 않는다.
- 글씨: 사진을 단톡방에서 폰 폭으로 볼 때 가장 작은 글씨(항목 "N건"·보조 줄)가 14px 이상, 숫자는 16px 이상으로 보이게 한다.
  - 요약 사진은 화면 폭 그대로 2배로 그린다(월 정리와 같음). 폰 폭으로 보면 화면에서 본 크기 그대로다.

### 결산 들어가는 길

- 장부 화면 위쪽 [결산] 을 흰 면 + 청록 아이콘 버튼으로 바꿔 [설정] 보다 눈에 띄게 한다(SPEC-001 v2.6 보강 "장부 첫 화면", 시안 A).
- 처음 결산을 열면 말풍선 3이 보내기 버튼을 가리킨다(SPEC-008).

### 기술 메모 (v2.6)

- 요약 화면은 새 컴포넌트(`YearShareSummary`, 가칭)다. 요약 카드 + 지금 `ItemTotalsCards` 를 다시 쓴다.
  - 계산은 지금 `yearReport`(수입·지출·잔액·`incomeItems`·`expenseItems`)와 `carryoverWords` 그대로다. 새 계산 없음.
  - `YEAR_VIEWS` 를 `summary` / `sheet` 로 바꾼다.
- 사진 만들기는 지금 `useSavePicture` 의 html2canvas 경로를 같이 쓴다(월 정리 사진 처리: `data-theme="light"` + `data-capturing`).
- 보내기: `features/backup/sendFile.ts` `shareFile` 을 갤럭시에도 쓴다. 지금 `savePicture.ts` 의 `share` 는 iOS 일 때만 있다.
  - 보내기(공유 창 우선)와 저장(지금 그대로: 갤럭시 내려받기 / 아이폰 공유 시트)을 두 동작으로 나눈다.
  - `NotAllowedError` 처리는 아이폰의 "한 번 더 누르기"(#58)를 같이 쓰는 방향이고, #114 결과로 정한다.
- 결산표 빈 머리 칸: `sheet/IncomeExpenseTable` 첫 `<th>` 에 화면 읽기 전용 글자. 인라인 hex 양식이라 보이지 않는 글자 스타일도 인라인으로 둔다.
- 위험: 갤럭시 크롬·삼성 인터넷·홈 화면 앱에서 `canShare({ files: [png] })` 가 참인지, 카톡에서 사진(파일 첨부 아님)으로 올라가는지, 만드는 시간 뒤에도 공유 창이 열리는지 — 모두 #114 에서 확인한다.

- 올해 결산은 v1 `components/report/*` 를 재사용하되 입력을 `MonthlyData[]` 대신 계산된 `YearReport` 로 바꾼다. 월 정리는 새 컴포넌트. 계산은 `domain/report.ts` 순수 함수(`monthSummary`, `yearReport`).
- 날짜순(v2.2, #77): 월 정리 수입·지출 내역과 올해 결산 지출내역 표의 달별 순서는 장부와 같은 `domain/entryDate.byDate`. 양식(`features/report/sheet`)은 그대로라 날짜 칸이 없다.
- 항목별 합계(v2.3, #84): `yearReport` 의 `incomeItems`·`expenseItems`(`ItemTotal` = 이름·금액·건수)가 v1 수입내역 합산(처음 등장한 순, 입력 순)을 대신한다. 같은 금액의 순서는 1~12월 × `byDate` 로 늘어놓은 기록에서 처음 나온 순(안정 정렬). 결산표 표는 `sheet/ItemTotalsTable`(인라인 hex, `tableLayout: fixed`), 앱 화면은 `ItemTotalsCards`(토큰, 막대 색 `--income-bar`·`--expense-bar`). [결산표 | 항목별 합계] 전환은 화면 안 상태(`useState`)라 방문 기록에 쌓지 않는다 — 안드로이드 뒤로 버튼은 어느 쪽에서든 장부로. 사진은 결산표만 찍으므로 [항목별 합계] 에서는 아래 고정 버튼을 그리지 않는다. 기록이 없으면 전환 버튼도 없다.
- 이미지: html2canvas 유지(oklch 회피용 인라인 스타일 유지). `canvas.toBlob` → Blob URL → `<a download>`. 아이폰은 `File(png)` → `navigator.share({ files })` (백업과 같은 `features/backup/sendFile.ts` `shareFile`).
