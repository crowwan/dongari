# SPEC-003 월 정리와 올해 결산

## 배경과 목표

v1 은 보고서를 PNG 로 '다운로드'해서 어머니가 갤러리·파일 앱에서 찾아 카톡에 다시 올려야 했다.

목표:
- 달마다 그 달 내역을 한 화면으로 정리해 보고, 사진으로 바로 보낸다 (월 정리).
- 1년치는 v1 연말 양식과 **똑같은 모양**으로 보고, 사진으로 바로 보낸다 (올해 결산).
- 화면에서 "보고서" 라는 말은 쓰지 않는다.

## 동작 정의

### 월 정리 (장부 화면 [N월 정리 보기])

```
┌───────────────────────────────┐
│ ← 장부로                       │
│ 2026년 9월 정리                 │
│ ┌ 수입 ───────────────────────┐│
│ │ 회비              140,000원 ││
│ │ 수입 합계          140,000원 ││
│ └─────────────────────────────┘│
│ ┌ 지출 ───────────────────────┐│
│ │ 대관료              40,000원 ││
│ │ 간식비              58,280원 ││
│ │ 지출 합계           98,280원 ││
│ └─────────────────────────────┘│
│ 8월까지 잔액       1,124,473원   │
│ 9월 수입 − 지출      +41,720원   │
│ 9월 말 잔액        1,166,193원   │
├───────────────────────────────┤
│      [ 사진으로 보내기 ]        │
└───────────────────────────────┘
```

- 수입·지출 내역은 그 달 기록을 입력 순으로, 이름이 같아도 합치지 않는다 (장부와 같게).
- 전달까지 잔액 = 이월금 + 1월~전달 수입 − 1월~전달 지출. 1월이면 "작년 이월금" 으로 표시.
- 그 달 기록이 없으면 이 화면으로 들어오는 버튼이 없다 (SPEC-001).

### 올해 결산 (장부 화면 위쪽 [올해 결산])

1. v1 `PLANS.md` 6장 양식 그대로: 월별 수입·지출 표 + 이월금·잔액, 좌우 분할 지출내역 표, 수입내역 항목별 합계.
2. 화면 폭에 맞게 줄여 보여 주고 손가락으로 확대해 볼 수 있다.
3. 기록이 하나도 없으면 양식 대신 "적은 내역이 있어야 결산을 만들 수 있어요" 안내, 보내기 버튼 비활성.

### 사진으로 보내기 (두 화면 공통)

- 하단 고정 큰 버튼 **[사진으로 보내기]** — 화면의 정리/결산 영역을 이미지로 만들어 공유 화면(카톡 등)을 연다.
- 그 아래 텍스트 버튼 [사진 저장] — 공유를 지원하지 않거나 저장만 원할 때.
- 이미지를 만드는 동안 "만드는 중…" 표시, 중복 누름 방지.
- 공유를 사용자가 취소하면 아무 안내 없이 원래 화면.
- 이미지는 화면 테마와 상관없이 흰 바탕(단톡방에서 읽기 쉽게).

### 계산 규칙 (기록 → 결산)

- 월별 수입/지출 = 해당 월 기록 합.
- 지출내역 표 = 월별 지출 기록을 입력 순서대로. 1~6월 왼쪽, 7~12월 오른쪽, 좌우 행 수 맞춤.
- 수입내역 = 수입 기록을 **이름별로 합산**, 처음 등장한 순서대로.
- 잔액 = 이월금 + 연간 수입 − 연간 지출.

## 기술 메모

- 올해 결산은 v1 `components/report/*` 를 재사용하되 입력을 `MonthlyData[]` 대신 계산된 `YearReport` 로 바꾼다. 월 정리는 새 컴포넌트. 계산은 `domain/report.ts` 순수 함수(`monthSummary`, `yearReport`).
- 이미지: html2canvas 유지(oklch 회피용 인라인 스타일 유지). `canvas.toBlob` → `File` → `navigator.share({ files })`.
- `navigator.share` 는 사용자 누름 직후(일시적 활성화)에만 호출되므로, 이미지 생성이 길면 실패할 수 있다 → 화면 진입 시 미리 생성해 두는 방식 검토 — 결정: 기술 검증 후 (첫 이슈)
