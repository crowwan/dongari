# SPEC-008 처음 쓰는 분 연습 장부

## 배경과 목표

v2.6 은 "이모가 처음 쓰는 날"에 맞춰 묶었다. 장부를 처음 만들고, 한 줄 적고, 월말에 정리를 보고, 연말에 결산을 단톡방에 올리고, 폰을 바꿀 때까지 처음 쓰는 분이 막히는 곳이 있다(접근성 점검 04·06·07: 위쪽 작은 [결산] 을 찾기 어렵고, 줄을 누르면 고칠 수 있다는 걸 모르고, 복구 코드가 왜 필요한지 모른다).

#122 는 이것을 **진짜 장부 위의 말풍선 네 개**로 풀었다. 그런데 말풍선은 그 기능을 쓰려는 순간에 화면을 어둡게 잠그고 끼어든다. 돈을 적으려던 참에 말풍선부터 닫아야 해서 오히려 길을 막고, 읽기만 하고 직접 해 보지는 않는다. 그래서 다시 설계한다(사용자 2026-10-16: "말풍선 스텝이 그 기능을 사용할 때 나오니까 좀 그런가" → "뭔가 하나를 입력하게 하고 지우는 식으로 예시를 직접 따라하게" → "이거 공유하는 것도 연습에 포함시켜").

이 기능이 끝나면 처음 쓰는 분은 첫 실행에서 한 번 "연습해 볼까요?" 질문을 받는다. 저장되지 않는 **연습 장부** 안에서 말풍선을 따라 직접 한 줄 적고, 정리를 보고, 지워 보고, 결산 사진을 내 카톡 "나와의 채팅"에 실제로 보내 본다. 진짜 장부는 처음부터 깨끗하다. 진짜 장부에는 복구 코드 안내 말풍선 하나만 남는다. 설정에서 언제든 다시 연습할 수 있다.

- 시안: 위 링크 "우리 장부 연습 흐름 시안" 흐름 19컷 + 결정 20개(사용자 결정 2026-10-16 "추천대로 진행" — 각 결정의 "(추천)" 값). 옛 시안(#122 말풍선 네 개)은 변경 이력에.
- 선행
  - SPEC-001: 장부 화면, 내역 적기(하나씩 채우기·연달아 적기), 고치기·지우기, [N월 정리 보기].
  - SPEC-003 v2.6 보강: 결산 [사진 보내기](가칭, #130 구현 중).
  - SPEC-005: 새 장부 만들기, 장부 종류별 기본 항목.
  - SPEC-006: 복구 코드·자동으로 지키기.
  - #110 `useModalLayer`(창 뒤 화면 잠금), #122 `CoachMark`(말풍선 부품).

## 동작 정의

### 기본 흐름 (첫 실행, 동아리 예시, 오늘이 10월 16일일 때)

시안 흐름의 컷 번호를 괄호에 적는다. 0~7 이 기본 길이고, A·B 는 공유를 못 했을 때의 갈래다.

| 컷 | 화면 | 말풍선 (연습 N / 4) | 가리키는 곳 | 누르면 |
|---|---|---|---|---|
| 0 | 첫 실행 물음 | — | — | [연습해 보기] → 1, [바로 시작] → 7 |
| 1 | 연습 장부 화면 (잔액 0원, "10월에 적은 내역이 없어요") | 회비 10,000원을 적어 볼게요. 여기를 눌러요 (1 / 4) | 아래 [+ 내역 적기] | 내역 적기 |
| 1-a | 내역 적기 "며칠인가요?" | 오늘 날짜를 눌러요 (1 / 4) | [오늘 16일] (날 칸도 열어 둔다) | 날짜가 정해지면 다음 질문 |
| 1-b | "무엇인가요?" | 회비를 눌러요 (1 / 4) | 기본 항목 [회비 · 수입] | 항목·수입이 정해지고 금액으로 |
| 1-c | "얼마인가요?" | 처음: +1만을 눌러 10,000원을 만들어요 → 10,000원이 되면: 10,000원이 됐으면 [저장]을 눌러요 (1 / 4) | 처음 [+1만] (금액 칸도 열어 둔다) → [저장] | 저장, 연달아 적기 "무엇인가요?" 로 |
| 1-d 앞 | "무엇인가요?" (날짜 10월 16일 그대로) | 간식비 5,000원도 적어 볼까요? (1 / 4) | 기본 항목 [간식비 · 지출] | 금액으로 |
| 1-d 앞 | "얼마인가요?" | 5,000원을 적고 [저장]을 눌러요 (1 / 4) | 금액 칸 → 5,000원이 되면 [저장] | 저장 |
| 1-d | "무엇인가요?", 위에 "장부에 넣었어요 · 2건" | 잘했어요! 다 적었으면 여기를 눌러 장부로 가요 (1 / 4) | [다 적었어요] | 장부 ("2건을 저장했어요") |
| 2 | 연습 장부 (잔액 5,000원, 수입 10,000·지출 5,000) | 이번 달에 얼마 쓰고 남았는지 여기서 봐요 (2 / 4) | [10월 정리 보기] | 월 정리 |
| 3 | 2026년 10월 정리 | (화면을 연 뒤 1초쯤 지나서) 다 봤으면 여기를 눌러 장부로 돌아가요 (2 / 4) | 위쪽 [‹ 장부로] | 장부 |
| 4 | 연습 장부 (회비·간식비 두 줄) | 잘못 적었으면 줄을 눌러 고칠 수 있어요. 간식비 줄을 눌러 봐요 (3 / 4) | 간식비 줄 | 내역 고치기 |
| 4-b | 내역 고치기 | 여기서 고치거나 지울 수 있어요. 연습이니 지워 봐요 (3 / 4) | [이 내역 지우기] | 평소 확인 창 "이 내역을 정말 지울까요?" → [지우기] → 장부, "지웠어요" |
| 5 | 연습 장부 (잔액 10,000원, 회비 한 줄) | 한 해가 끝나면 여기서 결산을 봐요. 눌러 봐요 (4 / 4) | 위쪽 [결산] | 올해 결산 |
| 5-b | 2026년 결산 (맨 위 "연습 · 진짜 결산이 아니에요" 띠) | 결산은 사진으로 보낼 수 있어요. [사진 보내기]를 눌러 카톡 '나와의 채팅'에 보내 보세요 (4 / 4) | 아래 [사진 보내기] | 폰 공유 창 |
| 5-c | 폰 공유 창 (폰이 그리는 창 — 앱 말풍선 없음) | — | — | 카카오톡 |
| 5-d | 카톡 "공유 대상 선택" | — | — | 맨 위 "나와의 채팅" → [확인] |
| 5-e | 카톡 나와의 채팅에 "연습" 띠가 찍힌 결산 사진 | — | — | 폰 뒤로 버튼·앱 목록으로 우리 장부에 돌아옴 |
| 6 | 끝 화면 "잘 보냈어요!" | — | — | [새 장부 만들기] → 7 |
| 7 | 새 장부 만들기 (지금 첫 실행 화면 그대로) | — | — | [만들기] → 진짜 장부 |
| A | 2026년 결산 (공유 창을 그냥 닫고 돌아옴) | 아직 안 보냈어요. 다시 눌러 보거나, 나중에 해도 돼요 (4 / 4) + [다음에 할게요] | [사진 보내기] | 보내면 6 "잘 보냈어요!", [다음에 할게요] → 6 "연습 끝!" |
| B | 2026년 결산 (공유를 못 쓰는 기기, PC 등) | 이 기기에서는 바로 보낼 수 없어요. 사진으로 저장해 두었다가 보내요 (4 / 4) + [다음에 할게요] | [사진으로 저장] | 저장하거나 [다음에 할게요] → 6 "연습 끝!" |

- 5-c·5-d·5-e 는 폰과 카톡이 그리는 화면이라 앱이 할 일이 없다. 그래서 5-b 말풍선 한 문장이 공유 창 안 길잡이의 전부다.
- 문자·다른 앱을 골라도 연습은 똑같이 이어진다(공유가 끝났다는 신호만 본다).

### 첫 실행 물음 (컷 0)

- **장부가 하나도 없는 폰에서 앱을 열면** 지금의 "새 장부 만들기" 대신 이 화면이 먼저 뜬다(시안 결정 "따로 한 화면 먼저").
  - 새 장부 만들기 화면 위에 카드로 얹지 않는다. 그 화면에는 이미 불러오기 두 줄 + 입력 세 칸이 있어, 카드를 얹으면 주 버튼이 둘이 되고 [만들기] 가 아래로 밀린다.
- 모양 (위에서 아래로)
  - 제목 "처음이세요?"(화면 제목).
  - 글 "돈 적는 법을 한 번 따라 해 볼까요? 연습 장부는 저장되지 않아서 마음대로 눌러 봐도 괜찮아요."
  - 카드 "따라 해 볼 것": 번호 붙은 네 줄 "회비 한 줄 적기" / "이번 달 정리 보기" / "잘못 적은 줄 지우기" / "결산 사진 보내 보기". 번호는 옅은 청록 동그라미(`--primary-soft` 면 + `--accent-ink` 글자).
  - 아래 고정: 주 [▶ 연습해 보기], 보조 [바로 시작], 그 아래 보조 글 "쓰던 기록을 옮기려면 [바로 시작] 뒤 위쪽 "불러오기"".
- [연습해 보기] → 연습 장부(컷 1).
- [바로 시작] → 지금의 첫 실행 "새 장부 만들기"(SPEC-005). 기록 파일·복구 코드로 불러오기도 그 화면 위쪽에서 한다(지금 그대로).
- 첫 실행 새 장부 만들기에서 안드로이드 뒤로 버튼을 누르면 이 물음으로 돌아온다(어느 길로 왔든). 물음에서 뒤로 버튼은 앱을 닫는다.
- [바로 시작] 을 고른 분께 다시 권하지 않는다. 설정 줄에 점 표시도 하지 않는다(시안 결정). "진짜 장부에서는 끼어들지 않는다"가 이번 변경의 뜻이라서다. 다시 하는 길은 설정 [연습해 보기] 하나다.
- 이 물음은 따로 "봤음" 을 남기지 않는다. 장부가 없으면 뜨고, 장부가 생기면 다시 뜨지 않는다.

### 연습 장부

- 이름 "연습 장부", 올해, 이월금 0원, 장부 종류는 첫 실행이면 동아리(아래 "가계부 예시").
- **폰 메모리에만 있다.** 앱의 `MemoryRepository`(지금 테스트용 저장소)로 연다.
  - 폰 저장소(`dongari:v2`)에 쓰지 않는다. 진짜 장부·장부 목록·기록 수가 바뀌지 않는다.
  - 기록 파일에 들어가지 않고, 자동으로 지키기(SPEC-006) 보관·상태 신호(SPEC-007)를 보내지 않는다.
  - 안내 상태(`dongari:guide`)도 바꾸지 않는다.
- 연습 동안에는 진짜 장부를 볼 수 없다. 돌아가는 길은 띠의 [그만하기] 와 끝 화면 둘이다.
- 연습 장부 화면에는 저장 안내 띠(SPEC-002), 7일 보관 안내(SPEC-006), 30일 기록 파일 안내와 [설정] 점 표시가 없다. 진짜 장부에 대한 안내라서다.
- 연습이 끝나면(끝 화면, [그만하기], 앱 닫기 어느 쪽이든) 연습 기록은 사라진다. 진짜 장부로 옮기지 않는다(시안 결정: 끝 화면에 "연습한 내역으로 시작" 선택 안 넣음). 시키는 대로 적은 가짜 돈이 진짜 장부에 섞이면 잔액이 틀어지고, 어디서 틀렸는지 찾기 어렵다.
- 화면 부품·규칙은 진짜와 같다. 내역 적기(하나씩 채우기·연달아 적기·[오늘 N일] 칩·빠른 더하기), 장부 줄 끝 ›, 고치기·지우기 확인 창, 월 정리, 올해 결산, 알림이 모두 평소 그대로 동작한다. 연습에서 익힌 것이 진짜에서 그대로 통해야 해서다.

### 연습 띠

```
┌───────────────────────────────┐
│ ⓘ 연습 중이에요       [그만하기] │  ← 옅은 회청 면(--info-bg) + 회청 글자(--info-ink)
│   저장되지 않아요                │
├───────────────────────────────┤
│ 연습 장부 2026년   [결산]  설정   │
```

- 연습 동안 **모든 화면 맨 위**에 붙어 있다(장부·내역 적기·고치기·월 정리·결산). 끝 화면에서는 사라진다.
- 모양
  - 높이 72 이상, 안쪽 여백 위 8·오른쪽 12·아래 8·왼쪽 20, 요소 사이 10.
  - 왼쪽 ⓘ 아이콘, 글 두 줄: "연습 중이에요"(Bold) / "저장되지 않아요"(14). 낱말 단위 줄바꿈.
  - 오른쪽 [그만하기]: 카드색 면(`--surface`) + 제목색 SemiBold 글자, 높이 56 이상, 반경 12, 줄바꿈 없음.
- 띠 색은 새 토큰 `--info-bg`·`--info-ink`(옅은 회청, 기술 메모 "새 토큰"). 노랑(`--warn-bg`)은 저장 실패 같은 경고, 옅은 청록(`--primary-soft`)은 "고른 것"이라 둘 다 뜻이 겹친다(시안 결정).
- **[그만하기] 는 말풍선이 떠 있어도 누를 수 있다.** 그만두는 길을 이 띠 하나로 모은다. 어느 화면에서나 같은 자리에 있어야 찾는다. "건너뛰기"는 한 단계만 넘기는지 다 그만두는지 헷갈려서 쓰지 않는다(시안 결정).
- [그만하기] → 확인 창 "연습을 그만할까요? 적은 연습 내역은 사라져요" [계속하기] [그만하기].
  - [그만하기]: 첫 실행이면 새 장부 만들기(컷 7), 설정에서 왔으면 진짜 장부 화면으로 간다. 연습 기록은 사라진다.
  - [계속하기]·뒤로 버튼: 확인 창만 닫고 그 자리 그대로. 말풍선이 다시 보인다.

### 단계 말풍선

- 모양은 #122 `CoachMark` 그대로다: 제목색 면 + 카드색 글자, 꼬리, 가리키는 곳 청록 둘레, 뒤 화면 스크림(아래 "모양"). 다른 점은 셋.
  - **[알겠어요]·[✕] 가 없다.** 가리키는 곳을 눌러야 다음으로 넘어간다(시안 결정). 연습에서 말풍선을 닫으면 다음에 뭘 할지 모른다.
  - 말풍선 아래 줄에 "연습 N / 4"(14 SemiBold, 80% 진하기, 고정폭 숫자)로 얼마나 남았는지 보여 준다. 단계는 넷: ① 적기(컷 1~1-d) ② 정리 보기(2·3) ③ 고치기·지우기(4·4-b) ④ 결산 보내기(5·5-b·A·B).
  - A·B 갈래에서는 아래 줄 오른쪽에 [다음에 할게요](카드색 면 + 제목색 Bold, 높이 56, 반경 12)가 생긴다.
- **뒤 화면은 어둡게 잠근다**(시안 결정). 누를 수 있는 것은 말풍선, 가리키는 곳, 띠 [그만하기] 뿐이다. 연습은 정해진 순서대로 가야 해서, 엉뚱한 곳(결산·설정)을 먼저 누르면 말풍선이 길을 잃는다. 저장되지 않는 연습이라 잠가도 답답할 일이 적다.
  - 가리키는 곳 말고 같이 열어 두는 곳: 1-a 날 칸(숫자를 쳐도 된다), 1-c·1-d 금액 칸(10000 을 쳐도 된다, 잘못 쳐도 고칠 수 있게).
- 연습 동안 말풍선은 늘 하나 떠 있다. 예외는 셋.
  - 컷 3: 월 정리를 연 뒤 1초쯤은 말풍선 없이 읽을 시간을 준다. 그동안에도 뒤 화면은 잠겨 있다(띠 [그만하기] 만).
  - 확인 창(지우기·그만하기)이 떠 있는 동안. 지우기 확인 창에서 [취소] 하면 4-b 말풍선이 다시 뜬다.
  - 폰 공유 창이 떠 있는 동안(앱이 그릴 수 없다).
- 다음 말풍선으로 넘어가는 때
  - 1-a: 날짜가 정해져 "무엇인가요?" 로 넘어가면. 날 칸에 아무 날이나 쳐도 된다.
  - 1-b·1-d 앞: 그 항목을 눌러 금액 질문으로 넘어가면.
  - 1-c: 금액이 10,000원이 되면 말풍선이 [+1만] 에서 [저장] 으로 옮겨 간다. 10,000원이 아니면 [+1만]·금액 칸에 머문다.
  - 1-d 앞 금액: 금액이 5,000원이 되면 [저장] 으로 옮겨 간다(빠른 더하기에 5천이 없어 금액 칸을 가리킨다).
  - 나머지: 가리키는 곳을 눌러 그 일이 끝나면(화면이 바뀌면).
- 화면 읽기
  - 열리면 포커스는 가리키는 곳으로 가고, 그곳의 설명(`aria-describedby`)은 말풍선 글 + "연습 N / 4" 다. 예: "내역 적기, 버튼, 회비 10,000원을 적어 볼게요. 여기를 눌러요, 연습 1 / 4".
  - Tab 순서는 띠 [그만하기] → 가리키는 곳(→ 같이 열어 둔 칸) → [다음에 할게요](있을 때).
- 연습 중 안드로이드 뒤로 버튼은 [그만하기] 와 같다(그만할까요 확인 창). 말풍선을 닫는 길이 없어서, 뒤로 버튼으로 엉뚱한 화면에 가면 순서가 깨진다.

### 연습 결산 사진 보내기 (단계 ④)

- 결산 화면은 SPEC-003 v2.6 보강 그대로다(처음 열면 [단톡방용 요약]). 아래 [사진 보내기] 를 가리킨다.
- 연습 결산 화면 맨 위와 **연습으로 만든 사진(보내기·저장 모두) 맨 위**에 검은 띠 "연습 · 진짜 결산이 아니에요" 를 찍는다(시안 결정 "위쪽 띠").
  - 띠: 사진 글자색 면 + 흰 Bold 글자, 가운데, 반경 4. 결산 카드·결산표 위 폭 그대로.
  - 단톡방 미리보기(작은 사진)에서도 맨 위 검은 띠는 바로 읽힌다. 대각선 워터마크는 옅어서 작게 보면 놓치고, 숫자 위에 겹쳐 결산을 읽기 어렵게 해서 쓰지 않는다.
  - 단톡방에 잘못 보내도 연습인 걸 안다.
- 말풍선은 카톡 "나와의 채팅"을 권한다(시안 결정). 어머니·이모는 카톡을 쓰고, 나와의 채팅은 아무에게도 안 가서 마음 편히 눌러 본다.
- 공유 결과에 따른 갈래 (`navigator.share` 결과, #130 `shareFile`)

| 결과 | 화면 |
|---|---|
| 공유 끝 (`shared`) | 바로 끝 화면 "잘 보냈어요!" |
| 공유 창을 그냥 닫음 (`cancelled`, AbortError) | 갈래 A: 말풍선 글 "아직 안 보냈어요. 다시 눌러 보거나, 나중에 해도 돼요" + [다음에 할게요]. 여전히 [사진 보내기] 를 가리킨다 |
| 누른 순간이 지나 거부 (`notAllowed`) | #130 규칙대로 버튼이 [한 번 더 눌러 보내기] 로 바뀌고, 말풍선 글이 "사진이 준비됐어요. 한 번 더 눌러 주세요" 로 바뀐다. 다시 누르면 위 표대로 |
| 공유를 못 쓰는 기기 (`canShare` 거짓) | 처음부터 갈래 B: #130 규칙대로 [사진 보내기] 가 숨고 [사진으로 저장] 하나만 있다. 말풍선은 [사진으로 저장] 을 가리키고 "이 기기에서는 바로 보낼 수 없어요. 사진으로 저장해 두었다가 보내요" + [다음에 할게요] |

- 공유 단계 건너뛰기는 "공유 창을 한 번 닫고 오면 [다음에 할게요]" 다(시안 결정). 공유 창을 한 번은 열어 보는 게 이 단계의 목적이다. 막히면 빠져나갈 길이 있어야 하고, 보낼 수 없는 기기에서는 처음부터 보인다.
- 갈래 B 에서 [사진으로 저장] 으로 사진을 다 저장하면(아이폰은 공유 시트를 닫으면) 끝 화면 "연습 끝!" 으로 간다.
- 공유가 끝났다는 신호가 갤럭시에서 실제로 오는지는 열린 질문이다.

### 끝 화면 (컷 6)

- 연습 띠가 사라진다. 위쪽 청록 동그라미 체크(72, `--primary-soft` 면 + `--accent-ink`).
- 제목: 공유를 마쳤으면 "잘 보냈어요!", 아니면([다음에 할게요], 갈래 B 저장) "연습 끝!".
- 첫 실행에서 연 연습
  - 글 "이제 진짜 장부를 만들어요. 연습으로 적은 내역은 지웠어요."
  - 카드 "배운 것" 네 줄: "[+ 내역 적기]로 한 줄씩 적기" / "[N월 정리 보기]로 한 달 보기"(N = 이번 달) / "줄을 눌러 고치고 지우기" / "결산 사진 보내기". 앞에 청록 체크. 공유를 마치지 않았으면 넷째 줄은 빈 동그라미.
  - 보조 글 "다시 해 보고 싶으면 설정 → 연습해 보기".
  - 아래 주 [새 장부 만들기] → 첫 실행 새 장부 만들기(컷 7, 지금 화면 그대로). 거기서 뒤로 버튼은 첫 실행 물음으로(위 "첫 실행 물음").
- 설정에서 연 연습
  - 제목 "연습 끝!", 글 "장부로 돌아가요". 배운 것 네 줄은 같다(공유를 마쳤으면 넷째 줄 체크).
  - 아래 주 [장부로] → 진짜 장부 화면. 진짜 장부·자동으로 지키기·기록 수는 연습 전 그대로다.
- 끝 화면의 뒤로 버튼은 그 화면의 주 버튼과 같다.

### 중간에 앱을 닫으면

- 첫 실행에서 연 연습: 다음에 열 때 첫 실행 물음을 **다시 묻는다**(시안 결정). 아직 진짜 장부가 없으니 전화가 와서 닫힌 경우가 많다. 연습 기록은 남아 있지 않다(메모리라서).
- 설정에서 연 연습: 다음에 열면 그냥 진짜 장부가 열린다.

### 설정 [연습해 보기]

- 설정 "앱" 묶음 맨 아래 한 줄(v2.6 #135 부터 그 아래에 누를 수 없는 버전 줄, SPEC-002): 이름 "연습해 보기", 보조 줄 "저장되지 않는 장부로 따라 해 봐요". 다른 줄과 같은 모양(줄 끝 ›).
  - 지금 "앱" 묶음은 홈 화면 앱이면 [홈 화면에 추가] 줄이 없어 묶음째 없다. 이 줄이 생기면 "앱" 묶음은 늘 있고, 홈 화면 앱에서는 [연습해 보기] 한 줄만 있다.
- 누르면 첫 실행 물음 없이 바로 연습 장부(컷 1)로 간다.
- 어머니가 이모 폰에서 같이 해 볼 때도 이 줄을 쓴다. 이모 폰이 처음이면 첫 실행 물음이 먼저 뜬다.

### 가계부 예시

- 첫 실행은 아직 장부 종류를 모르니 늘 동아리 예시로 한다(질문을 늘리지 않는다, 시안 결정).
- 설정에서 열면 **지금 장부 종류를 따른다**. 개인 가계부면 연습 장부도 가계부이고, 예시는 가계부 기본 항목(SPEC-005)으로 바꾼다.

| | 동아리 | 개인 가계부 |
|---|---|---|
| 수입 예시 | 회비 10,000원 | 용돈 10,000원 |
| 지출 예시 (지우는 줄) | 간식비 5,000원 | 장보기 5,000원 |
| 말풍선 글 | 위 표 그대로 | "회비"→"용돈", "간식비"→"장보기" 로 바꾼 글 (예: "용돈 10,000원을 적어 볼게요. 여기를 눌러요", "장보기 줄을 눌러 봐요") |
| 첫 실행 물음 넷째 줄·끝 화면 | "회비 한 줄 적기" | (첫 실행은 늘 동아리라 해당 없음) |

- 예시를 둘(수입 뒤 지출) 적는 이유: ③ 에서 한 줄을 지워도 결산에 남을 줄이 있어야 ④ 보내기를 눌러 볼 수 있다. 수입·지출을 한 번씩 적어 보는 것도 덤이다(시안 결정).
- ③ 에서 지출 줄을 지우는 이유: 점검 06 "줄을 누르면 고칠 수 있다는 걸 모름"을 직접 눌러 보며 푼다. 진짜 장부에서 지우기를 처음 눌러 보는 것보다 안전하다(시안 결정).

### 진짜 장부의 말풍선: 복구 코드 안내 하나만

#122 말풍선 네 개 중 **4번(복구 코드 보내기)만 남기고** 1·2·3번은 없앤다(시안 결정 E). 1·2·3번은 연습이 대신한다. 연습 장부에는 복구 코드가 없어 4번은 연습으로 가르칠 수 없다. 폰을 잃으면 기록이 다 사라지는 일이라, 기록 3건째에 한 번 [설정] 을 가리키는 건 끼어들 만한 값이 있다.

| 뜨는 때 | 가리키는 곳 | 문구 |
|---|---|---|
| 장부 화면, 모든 장부 기록 3건 이상, 자동으로 지키기를 쓸 수 있음(서버 주소 있는 빌드 + 켜짐 + 복구 코드 있음) | 위쪽 [설정] | 폰을 바꿔도 기록이 돌아오게 복구 코드를 보내 두세요 |

- 조건·문구는 #122 구현 그대로다. 실제로 보이는 때는 3건째를 저장하고 장부로 돌아온 직후(연달아 적기 [다 적었어요]·[← 장부로]·뒤로 버튼), 또는 그 뒤 처음 장부가 보일 때(앱 열기).
- 기록 수는 모든 장부를 합해 센다. 연습 장부의 기록은 세지 않는다(메모리라서).
- 자동으로 지키기를 쓸 수 없으면(서버 주소 없는 빌드, 꺼짐, 읽기 전용이라 복구 코드 없음) 띄우지 않는다. 다음에 장부로 돌아올 때 다시 본다. 켜지면 그때 뜬다.
- 장부를 지워 기록이 줄어도, 이미 본 말풍선은 다시 뜨지 않는다.
- 이 말풍선은 #122 모양 그대로 [알겠어요]·[✕] 가 있다(연습 말풍선과 다름). "연습 N / 4" 는 없다.

#### 모양 (4번 말풍선, 연습 말풍선 공통 부분)

│ 한랑드림 2026년   [결산] ┏설정┓ │  ← 가리키는 버튼: 스크림 위로, 청록 둘레
│ ░░░░░░░░░░░░░░░░░░░░░▲░░░░░░░ │

│ ░ │ 돌아오게 복구 코드를        │ │

│ ░ └─────────────────────────┘ │  ← 뒤 화면 어둡게 (스크림)

- 말풍선: 제목색 면(`--strong`) + 카드색 글자(`--surface`) — 알림(Toast)과 같은 짝이라 화면 위에 떠 있는 게 바로 보인다. 다크 모드에서는 이 짝이 그대로 뒤집힌다.
  - 화면 좌우 20px 안쪽 폭, 반경 16, 안쪽 여백 위 16·오른쪽 16·아래 12·왼쪽 18.
  - 글 Body 16 SemiBold, 줄 간격 1.45, 낱말 단위 줄바꿈.
  - 4번: 오른쪽 위 [✕](화면 읽기 이름 "안내 닫기", 56×56), 오른쪽 아래 [알겠어요](카드색 면 + 제목색 Bold 글자, 반경 12, 높이 56).
  - 연습: [✕]·[알겠어요] 없이 아래 줄 "연습 N / 4"(+ 갈래에서 [다음에 할게요]).
- 꼬리: 18px 마름모(45° 돌림, 반경 3)가 말풍선 위나 아래 가장자리에서 가리키는 곳의 가운데 쪽으로 나온다.
  - 가리키는 곳이 화면 아래쪽 절반에 있으면 말풍선은 그 위(꼬리 아래), 위쪽 절반이면 그 아래(꼬리 위).
- 가리키는 곳은 스크림 위로 올라오고 청록 둘레(3px `--accent-ink`, 바깥 3px 띄움)를 두른다.
- 뒤 화면은 스크림(`--scrim`, 라이트 60% / 다크 70%)으로 어둡게 한다. 연습 띠는 스크림 위에 그대로 보인다.
- 나타날 때 220ms 동안 아래 6px 에서 제자리로 올라온다(`cubic-bezier(.2,.8,.2,1)`). 동작 줄이기(`prefers-reduced-motion`)가 켜져 있으면 바로 나타난다.
- 누르는 곳은 56px 이상(design.md 기준).
- 가리키는 곳이 화면 밖이면(목록을 내려 버튼이 위로 밀림 등) 먼저 보이게 스크롤한 뒤 띄운다.
- 폰 글자를 키우면 말풍선 글도 같이 커진다(rem). 말풍선 높이는 글에 맞게 늘고, 가리키는 곳을 덮지 않는다.

#### 4번 닫기

- 닫는 방법은 넷이다.
  - [알겠어요]
  - [✕]
  - 안드로이드 뒤로 버튼: 말풍선만 닫는다. 화면은 그대로, 장부 화면이어도 앱이 닫히지 않는다(#110 확인 창과 같은 규칙).
  - **가리키는 [설정]**: 말풍선이 닫히고 설정이 열린다.
- 어떤 방법으로 닫든 **다시 나오지 않는다**(앱을 다시 열어도).
- 떠 있는 동안 앱을 닫으면 본 것으로 치지 않는다. 다음에 뜨는 때가 맞으면 다시 뜬다.

#### 4번 뒤 화면 잠금

- 떠 있는 동안 **말풍선과 [설정]만** 누를 수 있다. 나머지 화면은 어둡고, 누르기·Tab·화면 읽기가 닿지 않는다(점검 08, `inert`).
- 열리면 포커스는 [설정] 으로 간다. 그 버튼은 말풍선 글을 설명으로 읽힌다(`aria-describedby`).
  - 화면 읽기 예: "설정, 버튼, 폰을 바꿔도 기록이 돌아오게 복구 코드를 보내 두세요".
  - Tab 순서는 [설정] → [✕] → [알겠어요]. 닫으면 포커스는 [설정] 에 남는다([설정] 을 눌렀으면 설정 화면의 규칙을 따른다).
- 화면이 바뀌어 제목에 포커스를 준 뒤(#110 `useScreenHeading`) 말풍선이 뜨면, 포커스는 말풍선 규칙대로 [설정] 으로 옮긴다.

#### 4번을 하는 폰, 안 하는 폰

- **이 폰에서 첫 실행 "새 장부 만들기"로 첫 장부를 만들었을 때만 켜진다.** 연습을 했든([연습해 보기] → 끝 화면 → 새 장부 만들기), 안 했든([바로 시작]) 같다. #122 규칙 그대로다.
- 하지 않는 경우(#122 규칙 그대로 유지):
  - v2.6 을 처음 열 때 장부가 이미 있는 폰(v2.5 에서 넘어온 폰). 오래 써 온 분이고, 이미 기록 파일·복구 코드를 아는 분이 많다. 진짜 장부에 새로 끼어들지 않는다는 이번 뜻과도 맞다.
  - 첫 실행에서 기록 파일(옛 백업 파일)이나 복구 코드로 불러와 시작한 폰. 이미 쓰던 분이고, 불러온 데이터에 복구 코드가 같이 들어온다.
  - 장부 고르기 창의 [+ 새 장부 만들기] 로 두 번째 장부를 만들 때. 이미 쓰는 중이다.
- 설정에 "안내 다시 보기" 줄은 두지 않는다. 다시 보는 길은 [연습해 보기] 다(4번은 연습에 없다).

### 저장 위치

- 4번 안내 상태는 **이 폰에만** 둔다. localStorage `dongari:guide` = `{ v: 1, active: boolean, seen: number[] }` (#122 그대로).
  - `active`: 안내 켜짐.
  - `seen`: 닫은 말풍선 번호. 이제 4 만 쓴다. #122 시절 값에 1·2·3 이 있어도 읽기는 그대로 받고 무시한다(v2.6 은 아직 릴리스 전이라 미리보기·개발 폰에만 있다).
- 장부 데이터(`dongari:v2`)와 따로 두므로 저장 형식(`schemaVersion`)은 그대로다.
- **기록 파일과 자동으로 지키기 보관본에는 넣지 않는다.**
  - 이유 1: 파일이나 복구 코드로 옮겨 온 폰은 위 규칙대로 안내를 하지 않으니, 옮길 값이 없다.
  - 이유 2: 기록 파일 형식을 바꾸지 않아도 된다.
  - 이유 3: 폰마다 다른 값이다(`dongari:keep` 과 같다).
- 값이 없거나 깨졌으면 안내를 끈 것으로 본다. 쓰던 분을 귀찮게 하지 않는 쪽으로 한다.
  - 예외: 장부가 없는 첫 실행이면 "아직 정하지 않음" 으로 두고, 첫 장부를 만들면 켠다.
- 저장(localStorage 쓰기)에 실패해도 화면은 막지 않는다. 그 경우 다음에 앱을 열면 같은 말풍선이 한 번 더 뜰 수 있다.
- 연습은 기기에 아무것도 남기지 않는다. 연습을 했는지도 적지 않는다(첫 실행 물음은 장부가 있느냐로만 정한다).

### 예외와 경계 상황

- 4번: 확인 창·선택 창이 떠 있으면 띄우지 않고 기다린다. 창이 닫힌 뒤 다음에 장부 화면이 보일 때 띄운다.
- 4번: 저장 안내 띠(저장 실패·읽기 전용 시작)가 있으면 띄우지 않는다. 그 안내가 먼저다.
- 연습 중 화면을 돌리거나 폰 글자 크기를 바꾸면 말풍선은 가리키는 곳 자리를 다시 잰다(지금 `CoachMark` 그대로).
- 연습 중 날짜가 바뀌어도(자정을 넘김) 연습 장부의 오늘은 연습을 시작한 날로 둔다 — [오늘 N일]·"N월 정리 보기" 가 단계 중간에 바뀌지 않게.
- 지난 연도·새 연도 시작 화면은 연습에 없다(연습 장부는 늘 올해).
- 아이폰에서 키패드가 떠 있는 화면(1-a 날 칸, 1-c 금액 칸을 친 경우)에서도 말풍선은 가리키는 곳 위·아래에 자리를 다시 잡는다. 키패드에 가리는 [저장] 은 SPEC-001 `keyboard` 규칙대로 질문 바로 아래로 올라온다.

## 기술 메모

### 연습 장부

- 연습은 진짜 화면 부품을 그대로 쓰고 저장소만 바꾼다: `storage/MemoryRepository` 에 연습 장부 하나(이름 "연습 장부", 종류, 올해, 이월금 0)를 담아 연다. `MemoryRepository` 는 지금 "테스트용" 주석이라 앱에서도 쓰는 저장소로 주석을 바꾼다.
  - 자동 보관기(`NotifyingRepository`·`AutoKeeper`)·상태 신호·`guideStore`·`requestPersistentStorage` 를 연습 쪽에 넘기지 않는다. 그래서 AC-4 는 "연습 트리에 그것들이 없다" 와 "localStorage 쓰기가 없다" 로 테스트한다.
  - 구현(#132): `main.tsx` 는 `features/practice/AppRoot` 를 그리고, AppRoot 가 첫 실행 물음 → 진짜 `App` / 연습(`PracticeRun`) → 끝 화면(`PracticeEnd`)을 갈아 끼운다. 방문 기록은 물음 위에 이 앱 표시 칸 하나를 쌓고, 연습이 끝나면 연습이 쌓은 칸을 그 칸까지 되돌린다(첫 실행이면 그 칸이 새 장부 만들기 칸, 설정에서 열었으면 그 칸도 뺀다). 처음 방향: 연습은 `App` 을 `repository=new MemoryRepository(연습 데이터)`, `keep` 없음, `guideStore` 없음으로 한 번 더 그리고 그 위에 띠와 진행기를 얹는다. 진짜 `App` 의 상태(넘겨 본 달 등)는 연습 뒤 처음부터 다시 그려도 된다.
- 첫 실행 물음은 지금 첫 실행(`ledger.isFirstRun` → 새 장부 만들기) 앞에 한 화면을 더 둔다. 첫 실행 새 장부 만들기는 물음 위에 쌓는 방문 기록 칸으로 열어, 뒤로 버튼이 물음으로 오게 한다(#110 `useScreenHistory`).
- 연습의 "오늘"은 연습을 시작할 때 잡아 둔다(`options.now` 를 고정값으로 넘김).
- 예시 값(항목 이름·금액·말풍선 글)은 장부 종류별 한 곳(가칭 `features/practice/practiceScript.ts`)에 둔다. 단계 진행은 순수 함수로(가칭 `nextPracticeStep(step, 화면 상태)` → 다음 단계·가리키는 곳·말풍선 글) 단위 테스트한다.
- 가리키는 곳을 아는 방법: 지금 `GuideTargets` 처럼 화면 부품이 `ref` 를 받는다. 새로 필요한 곳은 [오늘 N일] 칩·날 칸, 기본 항목 줄(회비·간식비 / 용돈·장보기), [+1만]·금액 칸, 내역 적기 [저장]·[다 적었어요], 월 정리 [‹ 장부로], 장부 줄(이름으로), 고치기 [이 내역 지우기], 장부 [결산], 결산 [사진 보내기]·[사진으로 저장]. 루트 `data-testid` 가 있는 곳은 그것으로 찾는 방법도 구현 중에 고른다.

### 말풍선 부품

- `ui/CoachMark` 를 넓힌다(#122 부품 그대로 + 선택 항목).
  - [알겠어요]·[✕] 를 빼는 모양(연습)과 아래 줄 "연습 N / 4"·[다음에 할게요] 자리를 받는다.
  - 열어 둘 요소를 여러 개 받는다: 가리키는 곳 + 같이 열어 둘 칸 + 띠 [그만하기]. 지금 `useModalLayer(open, layer, focus, enabled, keepOpen)` 의 `keepOpen` 이 요소 하나라 목록으로 넓힌다(각 요소의 조상 줄은 남기고 그 줄의 형제만 잠금). 확인 창·선택 창은 지금처럼 부른다.
  - 말풍선 층(z-index 40)은 연습 띠보다 아래가 아니어도 되지만, 띠는 스크림 구멍처럼 밝게 남아야 한다. 띠를 스크림 위 층으로 올리거나 스크림 구멍을 둘로 내는 것 중 구현 중에 고른다.
- 진짜 장부 4번은 지금 `useFirstUseGuide`·`FirstUseGuideMark` 를 줄여 쓴다.
  - `GuideNumber` 는 4 하나, `GUIDE_MESSAGES` 는 4번 문구 하나. `nextGuide` 는 `screen === 'ledger' && entryCount >= 3 && keepUsable && !blocked && active && !seen.includes(4)`. `monthHasEntries`·`yearHasEntries`·`withPassedGuides`·`YEAR_GUIDE_TARGET`·`GUIDE_OPENS_SCREEN` 의 화면을 열지 않는 경로는 없앤다.
  - `guideStore` 는 그대로(`seen` 에 1·2·3 이 있어도 받는다). 켜는 곳(첫 실행 장부 만들기 성공 직후)·끄는 곳(진입점의 v2.5 폰, 첫 실행 불러오기 성공)도 그대로.
  - 뒤로 버튼·방문 기록은 #122 그대로: `openDialog('guide-4', onBack)`, [설정] 을 누르면 `open()` 이 말풍선 칸을 설정 화면 칸으로 바꿔 끼운다(`replaceState`).
