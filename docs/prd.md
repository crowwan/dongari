# 동아리 회계 PRD

## 한 줄 정의

동아리 회계를 맡은 어머니가 스마트폰으로 돈이 들어오고 나갈 때마다 한 줄씩 적으면, 연말 정산 보고서가 자동으로 만들어져 카톡으로 바로 보낼 수 있는 앱.

## 사용자와 상황

- **사용자**: 동아리 회계 담당(어머니). 스마트폰 위주, 작은 글씨와 복잡한 화면을 어려워함.
- **상황**: 회비를 걷거나 대관료·간식비를 낸 직후, 또는 한 달에 한 번 영수증을 모아 몰아서 입력. 연말(또는 총회 전)에 보고서를 만들어 단톡방에 공유.

### v1 에서 확인된 불편 (리뉴얼 이유)

| 불편 | 원인 (v1 구조) |
|---|---|
| 어디에 뭘 넣을지 헷갈림 | 월별 수입 총액, 월별 지출 상세, 연간 수입내역을 **따로** 입력하고 합계까지 직접 맞춰야 함 (같은 돈을 두 번 적는 구조) |
| 글씨·버튼이 작음 | 14px 이하 글씨, ✕/+ 기호만 있는 32px 버튼, 한 줄에 입력칸 2개 |
| 보고서 저장·공유가 어려움 | 이미지가 '다운로드'로 저장돼 갤러리·카톡에서 찾기 어려움 |
| (잠재) 데이터 유실 | 브라우저 저장소에만 있고 백업 수단 없음 |

## 핵심 경험

1. **한 줄 적기**: "언제 · 무엇에 · 얼마" 세 가지만 답하면 기록이 끝난다. 합계·검증은 앱이 한다.
2. **사진으로 몰아 적기**: 손으로 쓴 장부를 찍어 올리면 기록 초안이 채워지고, 이상한 값만 고쳐서 넣는다.
3. **보고서 보내기**: 버튼 하나로 기존과 같은 모양의 보고서가 카톡 공유 화면에 뜬다.
4. **안 잃어버리기**: 기록이 기기에 안전하게 남고, 백업 파일 하나로 새 폰에 옮길 수 있다.

## 범위

### 하는 것

- 거래 단위 입력(수입/지출), 수정, 삭제
- 연도별 장부, 전년도 이월금 자동 연결
- 기존 보고서 양식 그대로 생성, 이미지 공유
- 기기 저장 + 백업 파일 내보내기/불러오기
- 수기 장부 사진 인식 → 확인·수정 후 일괄 입력 (backlog)

### 하지 않는 것

- 로그인, 서버, 여러 사람 동시 편집
- v1 데이터 이전 (v2 는 새 장부로 시작)
- 사진을 기록에 첨부해 보관, 은행 연동
- PC 전용 레이아웃 (PC 에서는 폰 너비로 보임)

## 데이터 모델 (개요)

```
Ledger (연도별 장부 1개)
├─ year, clubName, carryover(전년도 이월금)
└─ entries: Entry[]
     Entry { id, month(1~12), type('income'|'expense'), name, amount, createdAt, batchId? }  // batchId: 사진으로 함께 넣은 묶음 (되돌리기용)

Settings { lastBackupAt?, lastChangedAt? }
```

- 월별 수입·지출, 지출 상세표, 수입내역(항목별 합)은 전부 `entries` 에서 **계산**한다. 저장하지 않는다.
- 자주 쓰는 항목도 저장하지 않고 전체 연도 `entries` 에서 최근 사용 순으로 계산한다 (SPEC-001 결정, #11).
- 저장 형식에 `schemaVersion` 을 둔다. 상세는 [ADR 001](decisions/001-storage.md).

## 기술 스택

- React 19 + TypeScript + Vite + Tailwind v4 (유지)
- 저장: localStorage + 버전 있는 스키마 + 저장소 계층 분리 ([ADR 001](decisions/001-storage.md))
- PWA (홈 화면 추가, 오프라인)
- 사진 인식(backlog): 직접 학습한 작은 모델 → ONNX → 브라우저 실행 ([ADR 002](decisions/002-photo-recognition.md))
- 테스트: Vitest + Testing Library (신규)
- 배포: GitHub Pages (유지)
