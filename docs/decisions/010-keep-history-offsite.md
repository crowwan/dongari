# ADR 010: 보관본을 날짜별로 남기고 서버 밖에도 둔다

- 상태: accepted
- 날짜: 2026-11-24
- 관련: [SPEC-011](../specs/SPEC-011-keep-history.md), [ADR 005](005-cloud-keep.md)(바꿈: "서버에 한 벌만"), [ADR 006](006-keep-status-signal.md), SPEC-006, SPEC-007
- 시안: https://claude.ai/artifact/YGW12D9fPMnTfQiZg9s5Ac (독립 점검 반영)

## 맥락

ADR 005 는 서버에 **최신본 한 벌만** 덮어쓰기로 정했다. 단순하지만 두 구멍이 있다.

1. 잘못 지우거나(엑셀로 덮어쓰기, 실수, 버그로 깨진 데이터) 그 상태가 10초 안에 보관되면 좋은 사본이 사라진다.
2. 모든 보관본이 Cloudflare 한 계정·한 KV 에만 있다. 계정 문제나 KV 를 잘못 지우면 한꺼번에 사라진다.

v2.8 엑셀 불러오기로 이모 장부(14년 치, 약 350KB)가 한 폰에 들어가면서 두 구멍의 값이 커졌다. 사용자(2026-11-24): "이 데이터 영구 보관을 어떻게 할지" → "최대한 복잡하지 않은 건 좀 포기하지만 그래도 안전성이 높아지니까 괜찮을 것 같아". 다만 "지금 당장 사용자에게 복구하는 기능을 제공하진 않아도 되지만, 복구 코드를 나한테 알려주면 내가 복구해줄 수 있는 방법 정도만 있어도 돼".

## 결정

1. **서버 날짜별 사본 (Worker + KV)**: 날이 바뀐 뒤(한국 시간) 처음 보관할 때, 서버에 있던 최신본을 그 보관일 사본으로 따로 남긴다(만든 때부터 31일 TTL). 달이 바뀌었으면 "지난달 마지막 모습"도 남긴다(약 400일 TTL). 기록을 고치지 않은 날은 사본이 없다. 오래된 사본은 KV 가 TTL 로 지운다(정리 작업 없음).
2. **서버 밖 주간 사본 (비공개 GitHub 레포)**: 비공개 레포 `crowwan/dongari-keep-backup` 의 GitHub Actions 가 주 1회 Worker 에서 모든 최신본을 암호문 그대로 끌어와 커밋한다. 커밋 이력이 곧 주간 사본이다. Worker 에는 이 일만 하는 읽기 토큰(`EXPORT_TOKEN`)을 따로 두고(요약 토큰 `REPORT_TOKEN` 과 분리), 레포 커밋은 그 레포의 `GITHUB_TOKEN` 으로 한다(개인 접근 토큰 없음). Cloudflare 와 다른 회사라 계정 문제에도 남는다. R2 는 같은 계정이라 이 목적을 채우지 못해 고르지 않았다.
3. **되살리기는 개발자가**: 사용자 화면(예전 날로 되돌리기)은 이번에 만들지 않는다. 개발자용 보관본 꺼내기 스크립트(`scripts/keep-rescue.mjs`)가 복구 코드로 있는 사본 목록을 보여 주고, 고른 날·달 사본이나 백업 레포 파일을 기록 파일로 만든다. 사용자는 그 파일을 [기록 파일 불러오기]로 연다.
4. **지켜보기**: Worker 가 마지막 내보내기 때를 기록해 요약(`/v1/report`)에 싣고, 보관 지켜보기(SPEC-007)가 8일 넘게 내보내기가 없으면 실패로 메일을 보낸다.

## 결과

- 좋음: 실수·버그로 망가진 상태가 보관돼도 최근 30일 안의 고친 날, 12달 안의 달 마지막 모습으로 돌아갈 수 있다. 보관 서버나 계정이 사라져도 주간 사본이 다른 회사에 남는다. 앱 화면은 바뀌지 않는다.
- 나쁨: 서버 코드와 운영 거리(비공개 레포·토큰 하나·워크플로 하나)가 늘었다. 되살리기에 개발자 손이 필요하다. KV 쓰기가 기기당 하루 최대 2번 늘었다(무료 한도 안).
- 알아 둘 것:
  - 서버와 레포는 여전히 암호문만 갖는다. **복구 코드를 아는 사람만** 내용을 볼 수 있다(개발자가 가족 코드를 받아 두면 개발자도 볼 수 있다).
  - 자동으로 지키기 끄기의 [지우기]는 최신본·상태 신호와 **날짜별 사본까지** 지운다. 서버 밖 주간 사본은 커밋 이력이라 남는다 — 지워 달라고 하면 개발자가 레포 이력을 손으로 지운다.
  - 여러 기기가 같은 코드를 쓰면 그날 마지막으로 보관한 기기의 모습이 그날 사본이 된다. KV 는 위치마다 최대 60초 늦게 보이니 자정 근처에서 하루 어긋날 수 있다.
