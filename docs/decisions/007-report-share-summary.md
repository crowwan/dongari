# 007. 결산은 단톡방용 요약 사진을 따로 만들고, 폰 공유 창으로 바로 보낸다

## 상황

지금 결산을 회원들에게 보내는 길은 두 가지 결정 위에 있다.

- **v1 연말 양식을 그대로 사진으로 만든다**(SPEC-003, ADR 003 "1년은 [올해 결산](v1 연말 양식 그대로)", design.md "토큰 예외: 올해 결산 양식"). 동아리에 내는 종이와 똑같아야 해서 11~12px 고정 글씨에 인라인 hex 로 그렸다.
- **앱 안 공유는 쓰지 않는다**(2026-10-06 SPEC-003 결정: 갤러리 저장만으로 충분). 갤럭시는 사진을 내려받고, 어머니가 갤러리에서 찾아 카톡에 올린다. 아이폰은 사진 앱에 넣으려고만 공유 시트를 쓴다(#58).

v2.6 접근성 점검(2026-10-16)에서 이 둘이 처음 쓰는 분과 회원들에게 가장 큰 걸림돌로 나왔다.

- 점검 03(높음): 결산표 글씨가 390 폭 화면에서 약 11px, 360 폭에서 약 9.5px 다. 폰 글자 크기를 키워도 그대로다. 저장되는 사진(720×2344)을 단톡방에서 폰 폭으로 보면 약 11px 이고 "대관/료" 처럼 낱말이 갈린다. 회원들이 보는 화면이 앱에서 가장 작은 글씨다.
- 점검 04(높음): 위쪽 작은 [결산] → [결산표] → [사진으로 저장] → 갤러리 "Download" 앨범 → 카톡 사진 첨부. 다섯 단계이고 중간에 앱을 떠난다.

## 결정

v2.6 시안 B 2안(사용자 결정 2026-10-16 "추천대로 진행", SPEC-003 v2.6 보강):

1. **v1 결산표는 "결산표(제출용)" 로 그대로 둔다.** 그와 별도로 단톡방에 올릴 **큰 글씨 요약 사진**을 만든다. 요약 사진은 수입·지출·잔액 큰 숫자 + 항목별 합계이고, 월 정리처럼 앱 화면 토큰으로 그린다. 결산 화면 전환은 [단톡방용 요약 | 결산표(제출용)], 처음은 요약.
2. **정리·결산 아래 주 버튼이 폰 공유 창(Web Share `navigator.share({ files })`)을 연다.** 갤럭시도 아이폰처럼 공유 창을 쓴다. [사진으로 저장] 은 보조 버튼으로 남긴다.
   - 버튼은 카카오 전용이 아니다. 받는 앱(카톡·문자·밴드…)은 공유 창에서 사용자가 고른다.
   - 버튼 이름과 갤럭시 공유 창 세부 동작은 기술 검증 #114 뒤 정한다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 지금 그대로 (v1 결산표 사진 + 갤러리 저장) | 바꿀 것 없음, 제출용과 단톡방용이 한 장 | 단톡방에서 글씨 약 11px, 보내는 길 다섯 단계, 앱을 떠남 |
| 1안: v1 양식을 사진용 큰 글씨(16px 이상)로 다시 그림 | 사진 한 종류 | 세로로 너무 길어짐, v1 과 "똑같은 모양"(SPEC-003 AC-7)을 잃음, 제출용 종이가 바뀜 |
| 결산표를 두세 장으로 나눠 보내기 (점검 03 제안) | 양식 유지, 글씨 조금 커짐 | 사진 여러 장을 고르고 보내는 일이 늘어남, 여전히 표 글씨 |
| **2안: 요약 사진 따로 + 결산표 제출용 유지 (채택)** | 회원들은 큰 숫자 몇 개만 읽음, 제출용 양식 그대로, 항목별 합계 카드(v2.3)를 다시 씀 | 사진이 두 종류라 어느 것을 보낼지 고름(전환 칸 이름으로 안내), 화면 하나 늘어남 |
| 카카오 SDK 로 카톡에 바로 보내기 | 카톡 단톡방까지 한 번에 | 카카오 앱 키·도메인 등록·SDK, 카톡만 됨, 사진 공유는 템플릿 제약 |
| **폰 공유 창 (채택)** | 브라우저 기능, 키 없음, 카톡·문자·밴드 다 됨, 아이폰은 이미 씀(#58) | 갤럭시 크롬·삼성 인터넷·홈 화면 앱 지원과 사진 만드는 시간 뒤 거부(`NotAllowedError`)를 실기기로 확인해야 함(#114), 공유 창 모양이 폰마다 다름 |
| 갤러리 저장만 (2026-10-06 결정) | 동작이 단순, 실패 거의 없음 | 점검 04 의 긴 길 그대로 — 보조 버튼으로 남겨 대체 길로 쓴다 |

## 결과

- 쉬워지는 것
  - 회원들은 단톡방에서 확대하지 않고 결산 숫자를 읽는다.
  - 어머니는 결산 화면에서 버튼 하나로 공유 창을 열고 단톡방을 고른다.
  - 동아리 제출용 결산표는 그대로다.
- 어려워지는 것
  - 결산 사진이 두 종류(요약·결산표)가 된다.
  - 공유 창 실패 경로(취소·거부·미지원)를 갤럭시에서도 다뤄야 한다.
  - 2026-10-06 "앱 안 공유는 쓰지 않는다" 와 SPEC-003 범위 밖 항목을 바꾼다.
  - 결산표는 여전히 작은 글씨(제출용)라 점검 03 은 요약 사진으로만 푼다. 결산표 화면 글씨는 그대로다.
- 다시 볼 조건
  - #114 에서 갤럭시 공유 창이 사진으로 올라가지 않거나 대부분 거부되면 주 버튼을 [사진으로 저장] 으로 되돌리고 이 결정을 다시 쓴다.
  - 회원들이 요약 대신 결산표를 계속 달라고 하면 처음 화면을 결산표(제출용)로 바꾼다.
  - 항목이 많아 요약 사진이 길어지면 줄이는 규칙을 정한다(SPEC-003 열린 질문).
