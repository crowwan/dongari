# ADR 011: 지켜보기 결과는 비공개 레포에서 보고, 앱 오류도 상태 신호에 싣는다

- 상태: proposed
- 날짜: 2026-11-25
- 관련: [SPEC-012](../specs/SPEC-012-watch-and-app-errors.md), [ADR 006](006-keep-status-signal.md)(고침: 누가 보는가), [ADR 010](010-keep-history-offsite.md)(같은 비공개 레포), SPEC-007

## 맥락

1. **결과가 공개돼 있었다.**
   - ADR 006 이후 "보관 지켜보기" 결과는 dongari 의 Actions 실행 요약에 남았다. 결과에는 기기별 마지막 신호, 마지막 보관 시각, 앱 버전이 들어 있다.
   - dongari 는 공개 레포라 실행 기록도 누구나 볼 수 있다. 그래서 어머니·이모가 언제 앱을 열었는지가 공개돼 있었다.
   - ADR 006 은 "Cloudflare 와 토큰을 가진 사람만 본다"고 적었다. 2026-11-25 점검에서 실제와 다르다는 것을 찾았다.
2. **앱 오류는 아무도 모른다.**
   - 오류 경계가 없어 화면을 그리다 오류가 나면 흰 화면이 된다. 개발자는 전화로만 안다.
   - ADR 006 은 오류 수집을 "사용자 몇 명에 과함"으로 뺐다. 그 뒤 사용자가 어머니·이모로 늘었고, v2.8 에서 엑셀 불러오기·회비 표 같은 큰 기능이 들어왔다.

## 결정

1. 지켜보기 워크플로는 **비공개 백업 레포**(ADR 010 의 주간 사본과 같은 곳)에서 돈다. 기기 이름표(`devices.json`)도 그 레포에 둔다. 원본 코드는 dongari `ops/keep-backup/` 에 두고 시험도 dongari 에서 한다.
2. **앱 오류**(화면 그리기 오류, 잡히지 않은 오류·Promise 거절, 기록 저장 실패)를 상태 신호에 실어 보낸다.
   - 서버에 평문으로 새로 남는 것: 오류 종류, 이름, 정리한 글, 화면 이름, 번들 위치, 횟수, 때.
   - 정리한 글은 숫자와 한글 같은 글자 덩어리를 지운 것이다.
   - 장부 내용, 복구 코드, 주소, 기기 정보는 여전히 보내지 않는다.
3. 화면 그리기 오류가 나면 흰 화면 대신 "다시 열기" 화면을 보인다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| **비공개 레포로 옮김 + 상태 신호에 오류 (채택)** | 있는 토큰·메일 길을 그대로 씀, 새 서비스 없음, 결과를 개발자만 봄, 60일 멈춤 없음(공개 레포 규칙) | 비공개 레포 Actions 시간(한 달 30분쯤), 원본(dongari)과 실행 위치(비공개 레포)가 나뉘어 손으로 옮김, 오류 위치가 번들 좌표뿐 |
| 공개 레포에 두고 요약에는 결과 한 줄만 | 옮길 일 없음 | 메일만 보고는 무엇이 문제인지 모름, 기기 이름표를 둘 곳 없음 |
| dongari 레포를 비공개로 | 한 번에 다 가려짐 | 무료 GitHub Pages 는 공개 레포만 됨(본 주소가 GitHub Pages, #189), dongari CI 가 비공개 CI 2,000분 한도를 씀 |
| Sentry 등 오류 수집 서비스 | 소스맵·묶기·알림을 다 갖춤 | 가입·SDK·외부로 나가는 데이터 검토, 사용자 몇 명에 과함 |
| Cloudflare 쪽 로그·알림만 | 서버 오류는 봄 | 폰 쪽 오류는 못 봄 |

## 결과

- **쉬워지는 것**
  - 지켜보기 결과가 공개되지 않는다.
  - 기기를 이름으로 본다.
  - 흰 화면 대신 "다시 열기" 화면이 나오고, 다음 아침 메일로 오류를 안다.
  - 예약 실행을 정각에서 옮겨 아침에 받는다.
- **어려워지는 것**
  - 요약 토큰을 두 레포(dongari 는 Worker 로 넣는 쪽, 비공개 레포는 부르는 쪽)에 맞춰 둬야 한다.
  - 오류 글을 정리해서 디버깅 정보가 준다. 위치는 같은 태그를 소스맵과 함께 다시 빌드해 찾는다.
  - 서버에 남는 평문이 오류 정보만큼 늘어난다(Cloudflare 와 요약 토큰을 가진 사람이 볼 수 있음).
- **다시 볼 조건**
  - 같은 오류 메일이 매일 와서 잡음이 되면 기준(36시간, 종류)을 고친다.
  - 사용자가 가족 밖으로 늘면 오류 신호를 끄는 설정을 둔다(ADR 006 과 같은 조건).
